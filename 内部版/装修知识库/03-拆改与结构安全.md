# 拆改与结构安全

> 拆改是装修第一坑，也是**唯一涉及房屋安全**的环节。**承重墙红线看这一篇就够了。**

## 🚨 承重墙安全红线（重中之重）

> **承重梁柱不能开槽；承重墙可开竖槽、尽量不开横槽、禁止长横槽；梁可打孔不能开槽；承重柱最好不动。** —— 范子超（全群共识）

### 国标底线（GB50327-2001）

| 红线 | 具体标准 |
|---|---|
| 横向开槽 | **严禁超过 300mm（30cm）**，禁止水平贯通槽、斜向槽 |
| 开槽深度 | **≤ 墙厚 1/3**（24cm 墙 = 8cm） |
| 槽距 | 500mm 内禁正反两面同时开槽 |
| 优先方案 | **竖槽（纵槽）破坏远小于横槽**，是承重墙布管优先方案 |
| 竖向主筋 | **不能切**（切横向钢筋影响相对小，竖向更严重） |

- 横槽仅限开关/插座点位极短，需用**钢筋探测仪避开主筋**。
- 边户全是承重墙、水泥砂浆层仅 1.5cm，走水电开槽必露钢筋。

### 一旦切到钢筋的处理流程

1. **先停工** → 2. **做结构鉴定**（别先修补！修补后无法鉴定） → 3. 不能直接水泥糊上 → 4. **要求物业/开发商出书面结构安全鉴定报告** → 5. 必要时报警

## ⚠️ 最关键避坑

- ❌ **拆承重墙/承重柱/构造柱** — 涉及整栋安全，严禁；构造柱与主体一体浇筑
- ❌ **盲信户型图** — 实际结构可能与图纸不符（125/126承重墙差异、公卫承重墙未标注、🔴 **117/125 承重墙图纸标非承重实际浇筑一体**）；**拆除前先让专业师傅探、看到钢筋要停手，图纸不可信**（金金金）
- ❌ **被报天价拆除费** — 团购900-1000，165户型6000虚高
- ❌ **退场没验收就给钱** — 拆项写进合同、验收合格再给尾款
- ❌ **铲反地梁**（2026-08-19）— 原以为是保温层计划铲，确认是反地梁后没动（娄星案例）；铲改前先确认地面结构
- ❌ **避雷「今旺拆除」**（🔴 2026-08-20 全群实锤）— 在业主家乱尿、明知承重墙仍砸、坐地起价（铲灰要300）、报价不报；"表面看便宜，只要有增项就巨坑"；原为团购推荐，已撤销

## ⏰ 最迟决策时点

- **拆改前**：办装修手续、向物业要砸墙图、确认哪些不能动。
- **水电开槽前**：定好空调、燃气（见 [[04-水电与燃气]]）。
- **砸墙后立刻叫物业打胶**，否则漏水。

## 🧭 回填与防水速查

### 回填方式
| 区域 | 回填方式 |
|---|---|
| 客厅/卧室（没水） | 建渣（最省钱） |
| 厨房（落差小） | 水泥通铺，不用回填 |
| 厨房（落差大）/卫生间 | 陶粒/发泡胶（防水） |
| 飘窗 | 建渣；厨房飘窗下沉用发泡胶 |
| 空调外机位坑 | 陶粒 |
| 生活阳台 | 不要填墙渣 |

### 防水
- **墙面防水必须撕**（邦泰柔性防水，不撕贴砖会掉砖），标准"墙刚地柔"。
- 卫生间必须做防水；厨房建议做（有水管漏水风险），可找东方雨虹来刷。
- **次卫防水：墙面必须铲、地面可以不铲**。

## ⚠️ 施工注意 & 验收

- 🔴 **砸完墙立刻叫物业打胶**（玻璃与墙体缝隙），否则漏水。
- 🔴 建渣先堆家里、统一清运，**别偷运**（划伤公区）。
- 🟡 施工时间限制：早8点前、12-14点、17点后不能作业；集中装修期周末也可施工。

### 🔴 打胶时机（2026-08-18，犯困蟹皇堡 @所有人）

> 核心："厨房沿着玻璃要砌墙的话，记得找物业窗框打胶。**打胶最晚节点在拆墙清理完垃圾、砌墙之前**，空档期估计就半天。"

- **飘窗砸完**应**立刻**给窗框下半部分打胶（犯困蟹皇堡自己就忘了，砸完直接砌墙）。
- **最佳做法**：砸完飘窗贴保护膜，**最后再打胶**；砌墙部分有担心就**提前打胶**。
- **补救措施**：里面做好防水 + 台面做好封闭 + 窗框外侧已有胶，基本不太会漏水；担心的邻居就**内外都打胶**。
- 已砌墙的邻居**不用纠结玻璃没打胶**（墙和玻璃接缝的胶就不是玻璃的打胶了，外面都打满防水胶）。
- ⚠️ **飘窗拆后要立马喊打胶师傅**：贴了玻璃保护膜后师傅不好打，要撕膜、擦不干胶印再打，可能不好看。
- ⚠️ **打胶师傅有排期**：提前约，否则等物业排期可能**至少一星期不能施工**。
- 窗框胶：同色找物业打；墙后面看不到自己打也可以。
- 🟡 拆除工期从1-2天变5天以上（受施工时间限制）。
- 🔴 **验收**：没验收不给钱；拆项写进合同；退场前必须验收确认。
- 🟡 **砌墙**：多数装修公司不包拆砌；建议找装修公司做（外面易出错），公司报价贵约一倍。
- 🟢 **拆砌墙自理（2026-08-18）**：美迪全包业主反映装修公司"包砌墙很贵，让我们在外面自己找"（拆改赚不到钱）；**外面找可省一半**（馨馨）；施工队"拆改吃力不讨好不赚钱"（犯困蟹皇堡）。
- 🟢 **165门框不能拆**（一体浇筑，拆大概率打出钢筋）。

### 保温层厚度争议
- 保温层厚度有 **8cm** 与 **3cm** 两种说法需实测；铲掉两边多16cm空间，但影响保温和隔音。

### 天花板保温层铲除 vs 保留
| 立场 | 理由 |
|---|---|
| 铲除 | 怕乳胶漆开裂，铲掉加高几寸层高 |
| 不铲（吊顶） | 吊顶完全覆盖，不影响隔音保温 |
| 不铲（石膏板封） | 比吊顶便宜、比全铲省事 |
| 不铲（搏一搏） | 开裂再修补 |

#### 🔴 顶部抗裂砂浆层专业讲解（2026-08-29，煌佳～正哥转发，犯困蟹皇堡置顶）

> "顶部这个不是保温层也不是隔音层，是聚丙烯防开裂砂浆层+挂网防开裂底灰。作用：楼板浇筑时有伸缩缝，防止后期刮腻子开裂。"

- **不铲的原因**：就是一层防开裂处理，铲了反而容易后期开裂。
- **正确流程**：水电之后用**空鼓锤检查**，空鼓、脱层才铲；没有空鼓不用动。
- **表面浮灰必须去掉**：即使不铲也要扫掉抗裂砂浆表面浮灰，**检查排除不能省略**。
