# 拆改与结构安全

> 拆改是装修第一坑，也是**唯一涉及房屋安全**的环节。**承重墙红线看这一篇就够了。**

## 🚨 承重墙安全红线（重中之重）

> **承重梁柱不能开槽；承重墙可开竖槽、尽量不开横槽、禁止长横槽；梁可打孔不能开槽；承重柱最好不动。** —— 范子超（全群共识）

### 国标底线（GB50327-2001）

| 红线 | 具体标准 |
|---|---|
| 横向开槽 | **严禁超过 300mm（30cm）**，禁止水平贯通槽、斜向槽 |
| 开槽深度 | **≤ 墙厚 1/3**（24cm 墙 = 8cm） |
| 槽距 | 500mm 内禁正反两面同时开槽 |
| 优先方案 | **竖槽（纵槽）破坏远小于横槽**，是承重墙布管优先方案 |
| 竖向主筋 | **不能切**（切横向钢筋影响相对小，竖向更严重） |

- 横槽仅限开关/插座点位极短，需用**钢筋探测仪避开主筋**。
- 边户全是承重墙、水泥砂浆层仅 1.5cm，走水电开槽必露钢筋。

### 一旦切到钢筋的处理流程

1. **先停工** → 2. **做结构鉴定**（别先修补！修补后无法鉴定） → 3. 不能直接水泥糊上 → 4. **要求物业/开发商出书面结构安全鉴定报告** → 5. 必要时报警

|---|---|---|
| **Liv**（125 边户） | 主次卧之间是**承重墙** | ❌ 不可打通，只能做**房中房** |
| **Jun.**（5-2901） | 次卧包进主卧、**没砸墙** | ✅ 可行（不动承重） |

## ✅ 一句话结论

- 🔴 **拆改前先办手续 + 探墙**：备案→动工证→预存 50 元、向物业要砸墙图；**图纸不可信，同户型也可能不准、以现场为准**。
- 🔴 **主次卧打通看承重墙**：承重墙只能做**房中房**；非承重墙可打通 + 口袋门（先探墙）。
- 🔴 **拆除报价**：团购 900-1000 元；**混凝土门洞/门垛另计**（三川原整套 2185）；165 户型报过 5200-6000。
- 🟡 **回填按区域选材**：客厅卧室建渣、厨卫陶粒/发泡胶；阳台保温层必须铲。
- 🔴 **顶灰铲不铲喷水试**（起泡掉皮就铲、不掉不铲）；**砌墙先填缝、竖着撑才稳**、主卧卫生间落地窗缝做止水梁。
- 🔴 **砸完飘窗立刻打胶**，最晚在砌墙之前（空档约半天）。
- 🔴 **打孔须事先书面报备**：9 栋 704 户打穿消防管网被归责；**打孔要签字 + 给物业报备**，否则出事不认。
- 🔴 **门洞/门垛遇混凝土**：多数师傅**不接**（另找人 400-800）；"物业说能拆/不能拆"口径矛盾，**敲开看有无钢筋**、图纸留物业。

## ⚠️ 最关键避坑

- ❌ **拆承重墙/承重柱/构造柱** — 涉及整栋安全，严禁；构造柱与主体一体浇筑。
- ❌ **盲信户型图** — 125/126 承重墙差异、公卫承重墙未标注、🔴 117/125 图纸标非承重实际一体浇筑。
- ❌ **想当然打通主次卧做衣帽间** — 先确认是否为承重墙；承重墙户型只能做**房中房**。
- ❌ **被报天价拆除费** — 团购 900-1000，165 户型 6000 虚高。
- ❌ **退场没验收就给钱** — 拆项写进合同、验收合格再给尾款。
- ❌ **铲反地梁**（08-19）— 确认是反地梁后没动（娄星案例）。
- ❌ **避雷「今旺拆除」**（🔴 08-20 全群实锤）— 乱尿、明知承重墙仍砸、坐地起价、报价不报。
- ❌ **打孔前不报备** — 9 栋 704 户打穿消防管网被归责；**打孔要签字 + 给物业报备**，否则出事不认（详见 [[14-小区与维权]]）。
- ❌ **只看"套餐价"定拆除** — 混凝土门洞 / 门垛 / 窗洞 / 地梁都是**另计增项**，先探明自家有几个混凝土位再签。
- ❌ **找不接混凝土的师傅硬干** — 师傅"混凝土不搞"就只能另找人（400-800），**换一个能一次处理混凝土的师傅整体更划算**（O耶''）。
- ❌ **赌"物业说能拆"** — 同一小区工程部给出**相反口径**；正解是**敲开看有没有钢筋**，并**把图纸留一份给物业**留痕。

## ⏰ 最迟决策时点

- **拆改前**：办装修手续、向物业要砸墙图、确认哪些不能动。
- **水电开槽前**：定好空调、燃气（见 [[04-水电与燃气]]）。
- **砸墙后立刻叫物业打胶**，否则漏水。

## 🧭 拆除前顺序（很重要）

1. **先到物业备案、领动工合格证**（8.3 备案 → 8.8 领证正式动工），办装修手续预存 50 元。
2. **务必向物业要砸墙图** —— 每个楼层图不一样（如 8 栋 4-7 楼共一张）；**户型图可能与实际不符**。
3. **先确认哪些不能动**：承重墙、承重柱、构造柱、梁、飘窗里的一体浇筑墙。

## 🧭 顶灰 / 保温层铲不铲（争议详解）

> **结论：喷水试验定夺 —— 起泡掉皮就铲、不掉皮不用铲。** 顶部那层不是保温层，是聚丙烯防开裂砂浆层 + 挂网防开裂底灰（煌佳～正哥专业讲解）：楼板浇筑有伸缩缝，防止后期刮腻子开裂。**铲了反而容易后期开裂。**

### 判断流程

- **正确流程**：水电之后用**空鼓锤检查**，空鼓、脱层才铲；没空鼓不用动。**即使不铲也要扫掉表面浮灰**（检查排除不能省略）。
- 临近飘窗处有约 20cm 宽、3cm 厚混凝土条铲不动，留 3cm 高低差需吊顶遮掩。
- **已呲水铲除的补救**：干透后刷**界面剂 + 挂网 + 防开裂底灰**再做后续工序。

### 两派立场对照

| 立场 | 代表 | 理由 |
|---|---|---|
| **能不铲就不铲** | 煌佳群、邦泰工程师、相睎、ni-yo | ni-yo：两种不同材质不可能一体浇筑，除非空鼓开裂，只需扫浮灰 |
| **要铲** | 贝塔贝塔（9栋2803）、宏师傅、黄师傅 | "一喷水一块块掉"、后期容易掉漆，湖南回南天梅雨季多 |
| 铲除 | — | 怕乳胶漆开裂，铲掉加高几寸层高 |
| 不铲（吊顶） | — | 吊顶完全覆盖，不影响隔音保温 |
| 不铲（石膏板封） | — | 比吊顶便宜、比全铲省事 |
| 不铲（搏一搏） | — | 开裂再修补 |

### 补充事实

- **多数建议不铲**（铲了楼上拖椅子都听得清）；有家铲多了钢筋外露 —— **建议别动顶面**。金金金：铲了会起泡，"开发商做还是做的抗裂砂浆层，只是可能有些地方手艺不好"。
- **顶保温层补充（彭才Peter）**：不是一体浇筑，是挂网后做的珍珠岩（含玻璃纤维），铲了掉渣扎人、耗时耗力耗钱。
- 保温层厚度有 **8cm** 与 **3cm** 两种说法需实测；铲掉两边多 16cm 空间，但影响保温和隔音。
- **公区保温层开裂**（金金金 10-2103 实测）：公区保温层开裂在修补，**不铲有可能会像这样开裂**、后面经常要补；刮腻子也会裂 —— 是个两难，建议咨询专业人士。
- **生活阳台 / 设备平台**：生活阳台漆铲不了；设备平台涂料好，不建议铲；开发商防水应付验收、毛坯要自己做。

## 🧭 回填与防水速查

### 回填方式

| 区域 | 回填方式 |
|---|---|
| 客厅/卧室（没水） | 建渣（最省钱） |
| 厨房（落差小） | 水泥通铺，不用回填 |
| 厨房（落差大）/卫生间 | 陶粒/发泡胶（防水） |
| 飘窗 | 建渣；厨房飘窗下沉用发泡胶 |
| 空调外机位坑 | 陶粒 |
| 生活阳台 | 不要填墙渣 |

- "房间用建渣最省钱，厨卫用陶粒或发泡水泥"；用轻质砖够，尽量别用红砖；回填**不建议用钢筋**（太重）。
- 飘窗回填专业解答（犯困蟹皇堡）：**客厅卧室完全没水用建渣**；厨房砸完落差小**水泥通铺不用回填**；落差大或卫生间**用陶粒/发泡胶**（**发泡好一点，陶粒可能有点味道**）。
- **楼板圆孔滴水**（云若依 7-2001）：楼板圆孔滴水泥/水、楼上干干净净 —— 怀疑**楼板/地漏断层**；照亮家地漏断层被验房查出已修好（验房要多查这类问题）。
- ⚠️ **反地梁不能铲**（08-19，娄星案例）。

### 防水（详见 [[05-防水与贴砖]]）

- **墙面防水必须撕**（邦泰柔性防水，不撕贴砖会掉砖），标准"墙刚地柔"。
- 卫生间必须做防水；厨房建议做（有水管漏水风险），可找东方雨虹来刷。
- **次卫防水：墙面必须铲、地面可以不铲**。

### 🔴 打胶时机（硬节点，别错过）

> 核心："厨房沿着玻璃要砌墙的话，记得找物业窗框打胶。**打胶最晚节点在拆墙清理完垃圾、砌墙之前**，空档期估计就半天。" —— 犯困蟹皇堡 @所有人

- **飘窗砸完**应**立刻**给窗框下半部分打胶（犯困蟹皇堡自己就忘了，砸完直接砌墙）。
- **最佳做法**：砸完飘窗贴保护膜，**最后再打胶**；砌墙部分有担心就**提前打胶**。
- **补救措施**：里面做好防水 + 台面做好封闭 + 窗框外侧已有胶，基本不太会漏水；担心的邻居就**内外都打胶**。
- 已砌墙的邻居**不用纠结玻璃没打胶**（墙和玻璃接缝的胶就不是玻璃的打胶了，外面都打满防水胶）。
- ⚠️ **飘窗拆后要立马喊打胶师傅**：贴了玻璃保护膜后师傅不好打，要撕膜、擦不干胶印再打，可能不好看。
- ⚠️ **打胶师傅有排期**：提前约，否则等物业排期可能**至少一星期不能施工**。
- 窗框胶：同色找物业打；墙后面看不到自己打也可以。
