# 防水与贴砖

> 泥瓦工程：防水做不好楼下发霉、贴砖不好会掉砖。**防水是重中之重。**

## ✅ 一句话结论

- 🔴 **墙面柔性防水必须撕**（墙刚地柔）；**主卧卫生间落地窗缝要砌墙 / 止水梁**；卫生间必做、厨房建议做；**阳台有洗衣机/热水器必做**。
- 🔴 **防水两遍**（回填前 + 面层，全包说的"四次"是横竖刷拆开算）；**签约前确认"回填前防水"是否包含**（有的默认不包、后期即增项）；**沉降层必须丙纶布 + 柔性涂料**，回填后再整个湿区做一遍。
- 🔴 **闭水试验**：蓄水 >2cm 泡 48 小时，**亲自去楼下看天花板**；**地漏须在最低位**（不得高于地面）。
- 🟡 **回填按区域选材**：没水处（客厅卧室）建渣最省、卫浴用陶粒/发泡胶；**卫生间回填物业建议不用发泡水泥**（存争议）。
- 🟡 **瓷砖认佛山砖**；木纹砖 40-85/片（主流 68-70），判据＝精雕数码釉、看工厂不看品牌；浴室墙选**柔光**。
- 🟡 **美缝 10-16 元/平**（半包全包都不包，**别早做**、排硬装后期）；材料＝**氢化环氧彩砂 / 天冬纯聚脲 / 桶装氢化彩砂**；**平缝是深水区**（出油师傅 + 白刚玉；锐思可寄砖调色）。
- 🟡 **卫生间墙砖标配 400×800**，600×1200/715 大砖加钱（2 千~5 千）；厨房墙面用贴膜或珐琅板磁吸。
- 🟡 **找平**：冲筋按位置补（砸飘窗处 / 柜子归方 / 门边 / 玄关餐边柜，金属衣柜不冲）；墙固**开槽后**刷；有地暖必须**瓷砖薄贴**，空鼓率 <5%。

## ⚠️ 最关键避坑

- ❌ **墙面防水不撕就贴砖** — 柔性防水会掉砖，标准"墙刚地柔"。
- ❌ **厨卫回填用建渣** — 走管道/落差大用陶粒/发泡胶。
- ❌ **瓷砖空鼓率高** — 贴完要验收（空鼓率＜5%）。
- ❌ **地暖与贴砖不协调** — 有地暖要瓷砖薄贴（精找平）。
- ❌ **美缝做太早** — 会被后续刷漆等工序刮花；且高峰期要排队，需早了解。
- ❌ **先刷墙固再开槽** — 开槽粉末会破坏墙固层，应开完槽再刷。
- ❌ **地漏做在高于地面 / 非最低位** — 水排不走；物业会抽检、要求整改"地漏过高"。
- ❌ **主卧卫生间落地窗缝只放坡不砌墙** — 群内一致"砌墙 / 止水梁"，更防洪（做地暖的更要砌）。
- ❌ **阳台有洗衣机/热水器却不做防水** — 实案"水顺燃气管道漏到楼下"（涸辙之汝）；**管根与厨房烟道根部另需重点处理**。
- ❌ **收房不查阳台地漏沉槽** — 顶豪群多家发现**沉槽里全是水泥**（"修房子的时候就进去了"，母脑斧 / Jenduek）；**先去楼下拧开沉槽盖清掏，再做封堵**，否则排水不畅。
- ❌ **被"打不到"打发就不打窗框胶** — 下沉处**须先拆保温板、清渣**才能打（陳風澈）；8 元/米打胶**不含填缝**（填缝另约 168 元）。
- ❌ **木纹砖只认品牌** — "很多都是**贴牌**的，**哪个厂产的才决定质量好坏**"（罗浮威尔底标实为贴牌，商家自认）。
- ❌ **同款砖不拿比价记录硬谈** — 东岸砖家严选同款女销售报 85，拿记录找老板当面谈成 **68**（差 17 元/片）。
- ❌ **把"金丝绒"当木纹砖买** — 两种釉面工艺价不同；"**买木纹砖就别考虑金丝绒了，本末倒置**"（哩梨李荔OvO）。
- ❌ **人字拼没算账** — 人工贵 17 元/平、费砖显缝、"后期容易显脏但个性"；美缝按平米计价不受铺法影响。
- ❌ **美缝用装修公司送的** — 送的多是**真瓷胶**，柔光砖"亮亮的不得行"（Jenduek"笑晕了，不想说话"）；9-2401"送的对不上色号吧"。
- ❌ **平缝随便找个师傅** — 金金金"**试了好几个师傅，卫生间都快被师傅试完了**"；非"出油"工艺"**做完手一摸就会被擦黑**"；自做翻车（"我自己上手了，发现不行"）。

## ⏰ 最迟决策时点

- **贴砖前**：决定通铺还是过门石、瓷砖款式、地暖是否装（地暖要贴砖前定，见 [[06-地暖]]）。
- **防水后、贴砖前**：做闭水试验。

## 🧭 防水

### 基本规则

- **墙面防水必须撕** —— 邦泰交房是柔性防水，不撕就贴砖会掉砖。**撕了之后墙面用刚性防水**（"墙刚地柔"）。
- 案例：有业主厨房防水撕了后渗水到墙里（撕完必须重做）。
- **墙面防水高度**：淋浴区 ≥1.8 米，干区 ≥1.2 米。
- **次卫**：墙面必须铲、地面可以不铲。

### 做几遍 & 材料

- **标准流程**：**回填前做一遍 → 回填 → 回填后再做面层防水 → 水泥砂浆贴砖**。
- **全包公司说"做四次"**：是把横竖刷拆开算（一遍横刷 + 一遍竖刷 = 一次），实际还是两遍。
- **地面柔性防水建议重做**；墙面用刚性。
- **回填加钢丝网**（防开裂）。
- 🔴 **"回填前防水"不必然包含（2026-09-16）**：母脑斧发现**小居配齐先布管 → 发泡水泥回填 → 再刷面层**，问出"**不包回填前的防水**""标准就是这样"，牛康铣"**这个就是妥妥的增项**"；设计师李进解释"不放心可以把厨房防水不刷、给我刷一下回填前""其实不刷也没有问题，**终身质保售后**（隐蔽工程）"。
- **并行做法（Alaric Lee / 小猪佩奇）**："**找平后做防水**""**回填前是开发商防水，底部我没铲**""**找平后刷 3 遍防水**"；庆"**第一遍刷不刷影响没那么大，次卫可以用开发商自带的打底**""**我是保留了地面的防水**"。
- 🔴 **煌佳丙纶布标准工艺（2026-09-18，正哥实录，ni-yo 转发）**：
  - **沉降层地面必须"丙纶布 + 柔性涂料"**（即大家看到的天蓝色）——"回填材料没有柔性，一干透就容易**顶破柔性防水**，有的卫生间没用几年就漏水一般都是防水没到位；**丙纶布是封闭防水效果最好、最保险的一种**"。
  - **精工流程**：丙纶布包管（侧面和地面**包到地面高度、上翻到顶**）→ **两遍防水涂料** → **分区回填（50-60cm 一格、砌单砖 6 公分）** → 植筋网找平（"分隔仓是为了分散压力，保证回填不塌陷不下沉"）。
  - **植筋红线**："钢筋**不是直接放陶粒上**（那样就是分层，起不到承重效果）；**植筋不能打到底部**，否则防水不起效果"；"**厨房地平面以下、卫生间下沉层不能打孔植筋，这是硬伤**"；"**低于层板厚度的反水梁不要植筋**"。
  - **开发商防水铲不铲**：墙面（贴砖）要铲、**地面不要铲**——"用电锤打会损坏沉降层结构"。
  - **砌墙/反水梁**："砌墙倒反水梁**一定要先做防水**再做接下来的工作。"
- 🔴 **"直接回填再防水"两派（2026-09-18，板栗案例）**：板栗家（美迪）**发泡水泥已直接回填**、"回填完再防水就是他们的工艺"，拆重做"怕碰到水管"、加做防水"要加钱"、防水质保 **10 年**——纠结拆不拆。**劝别拆派**：庆"做了最好，没做再去拆，沉没成本高了""闭水试验做好就行""破坏了没事，只有下沉那块防水还在就行"；AKAI"拆了成本变高，基础工艺应该没问题"；母脑斧"发泡水泥的全这样做""漏只有下水管破那种情况"。**施压派**：木瓜"别内耗，让他们重搞，不按工艺来承诺拆了重做的"。**底线动作：回填后整个湿区的面层防水 + 闭水试验必须盯**。
- **存水弯**：王超"不做沉水弯防臭？" → 庆"**马桶可以不做，如果马桶带存水弯的话**"；地漏肯定要做（王超）。
- **参考工序（"茶说"五道）**：区域划分 + 堵漏宝节点强化 → 界面剂 → 初次防水 → 二次防水 → 完工清场。
- **厨房/生活阳台一起刷**：王超"厨房不用做防水吧，生活阳台需要做" → Asen 教练"反正都来刷，一起刷了呗"。

### 闭水试验

- 蓄水深度超 2 厘米，持续 48 小时，**亲自到楼下邻居家检查天花板**。
- ⚠️ **地漏须在最低位**（不得高于地面）：物业会**定向抽检**、整改"地漏过高"（ni-yo）；七転八起"**不在最低位、高于地面**，我家也是"（空调机位，后期回填没管）。
- **卫生间回填争议（2026-09-11）**：物业口径"卫生间**不要用发泡水泥回填**"（娄星）→ 庆/乘以四/母脑斧认为堵管非回填所致（管子够高）；方案仅有**陶粒 / 发泡水泥**两种。

### 阳台 / 烟道做不做（按用水设备判定）

- **纯生活阳台（无用水设备）**：多数人**没做**（面包大亨"没必要吧，没看到有人做"、🌸"不用做"）→ ✗ 可省。
- 🔴 **有洗衣机 / 燃气热水器 / 走水管的阳台**：**必须做** —— 云若依"**因为有洗衣机和热水器肯定要做吧**"；涸辙之汝实案"**我家用水就顺着燃气管道漏到楼下了**"（附图）；我要睡觉"**千思会做 30cm**"（上返高度参考）。
- 🔴 **厨房烟道根部也要做防水**：星辰不锈钢门套（商家）"厨房**烟道那里也要做一下防水**，不然**水会顺着往下流**"。
- ⚠️ **重点部位**：管根、烟道根部、地漏周边 —— 这些是"水顺管往下流"的通道。

### 🟡 阳台地漏：连管 vs 装地漏（主群）

- **娟**"装修公司没给我们装地漏，总感觉不对" → **乘以四"是不是直接给你连洗衣机下水管了"**、**AKAI"没装、直接连的管子，说装地漏可能返水**"（娟"我这个也是这样说的"）。
- **顾虑与解法**：娟"淋浴挨着阳台肯定会过水" → **狗哥"阳台去做坡度，然后地漏改管**"；庆"扫到湿区就好"；娟家"**挨着阳台抬高几公分做了挡水**"；庆"刚看了我家确实还留了阳台地漏"——**两种现状并存，"装地漏会返水"是装修公司主流口径**。

### 🔴 楼上楼下卫生间渗水纠纷（璟和群，1 栋）

> 楼上卫生间施工、楼下渗水——**"闭水通过 ≠ 终身不漏"的现成案例**，也是邻里纠纷处理范本。

- **楼下口径（小604）**："**我都跟你们反应过多少次了，但问题还在，而且你们目前砖都贴好了**""我交给物业了，免得影响邻居关系，但目前问题还在"。
- **楼上口径（面包大亨，1 栋）**："**做了 3 遍防水，顶层增项加了丙纶布，闭水测试也通过了，现在渗水我在找原因**""48 小时防水测试底下是干的，测试通过后第二天贴的砖""**你们检查一下你家的主管子连接处是不是破了**""**如果因为我家防水没做好，你家造成的直接损失我全部承担，绝不推卸**""我还约了雨虹的人明天来看"。
- **劝架与解法**：佳（楼上家人）"**别升级矛盾**""他们防水的给不到具体的结论就挖了重做"；**niyo 家装修公司当日上门帮看**；双方同意交物业 + 第三方排查。
- **沉淀**：① 楼下渗水**先查主管连接处/管根再定责**（不一定是防水层）；② 楼上**主动留痕（防水工艺记录）+ 明确担责口径 + 主动约第三方**是化解纠纷的三件套；③ 当众质问只会升级（"天天找我老婆麻烦，没完了是不是"）。

### 厨房做不做：两派

| 立场 | 理由 | 代表 |
|---|---|---|
| **主张做** | 厨房有水管漏水风险；漏到客厅最后还是漏楼下 | 犯困蟹皇堡、牛康铣（"有水的地方都做"） |
| **主张不做** | 厨房**没有地漏**；主流做法是卫生间+生活阳台做 | 17_D、30、名匠（口径同） |

- **不做防水的兜底方案**：水浸传感器 + 智能水阀（漏水自动关阀报警），见 [[11-智能家居]]。
- 找东方雨虹来做是群内常见推荐。

### 排水与返味

- **同层排水不能做存水弯**（堵了要撬地面）；**异层排水才做**。
- **7 栋厨房污水返味案例**：楼上污水排入楼下厨房管道 → 装修公司用**弯管堵上 + 做好防水 + 拍视频留证据**防纠纷（母脑斧）。
- 飘窗（含厨房）防水一定要做好。
- 🔴 **阳台地漏沉槽被水泥堵（2026-09-14，顶豪群，多户同款）**：母脑斧"你们知道吗**阳台的地漏那个管理里面都是水泥**""还没做到那种需要用水泥的步骤，里面就都是水泥了，**应该是修房子的时候就进去水泥了**""**要去楼下拧开盖子，把水泥挫出来**"；Jenduek"我昨天好像也发现了""**我昨天扒拉出来的**"；AKAI"我家去楼下通了"；噜噜噜"我家也是之前去楼下通了"；👻"这个有可能是**开槽的时候用水冲洗然后流进去了**""**去楼下把那个沉槽拧开放出来**"；母脑斧"拿个东西堵一下，免得又进去了"。
- 🔴 **对"小区堵管"的新解释路径**：母脑斧"**有可能你们五栋下面的水管堵了根本不是装修的问题，可能开发商修房子的时候就搞堵了**" → 除"楼上倒水泥水"外，**交付时沉槽内已有水泥**亦是可能成因；排查时应先自查看沉槽（对照 [[14-小区与维权]] 5 栋堵管事件）。
- 🔴 **设备平台地漏堵 + 验房报告翻案（2026-09-20，主群）**：母脑斧家**设备平台下水口塞了垃圾和笔（笔上还刷了防水）**；物业"砌墙都没做、不能界定是不是遗留问题"踢皮球、"扯皮一上午、开发商不认" → **翻出验房报告"验房的时候就没通"才扳回**（狗哥"那就可以掰扯清楚了"、1-2602"专业验房的必要性就体现出来了"）；十九"**好多户都是堵的，我也是堵了**""教物业搞说要两三周，后面装修公司自己顺手搞了""物业工程部就是拖着"；庆"先问楼下邻居，好搞自己搞快很多；**闭水试验还是要联系楼下的，早加上也方便**"。⚠️ **"现在深刻意识到啥都要留痕"**（母脑斧）。交涉细节见 [[14-小区与维权]]。
- 🟡 **设备平台开发商放水层**：次且问"放水（防水）是原来就有还是装修做的" → 母脑斧"原来就有，**铲掉了不要了**" → 狗哥"**开发商做的防水都不要**"（与"墙面防水必须撕"同口径）。

## 🧭 回填

| 区域 | 回填方式 |
|---|---|
| 客厅/卧室（没水） | 建渣（最省钱） |
| 厨房（落差小） | 水泥通铺，不用回填 |
| 厨房（落差大）/卫生间 | 陶粒/发泡胶（防水） |
| 飘窗 | 建渣；厨房飘窗下沉用发泡胶 |
| 空调外机位坑 | 陶粒 |
| 生活阳台 | 不要填墙渣 |

> "房间用建渣最省钱，厨卫用陶粒或发泡水泥" —— Y.
> "本质为了防水，卫生间才用吸水的，没水的地方用建渣就行了" —— 线条小狗哥

**为什么别早做**：Kyleee 指出 **聚脲/环氧若先做，后面刷漆等工序会刮花弄乱** —— 这也是美缝普遍排到硬装后期的原因。

**为什么厕所可以先做**：厕所贴完砖、沉降池水干后就做最好 —— 后面各工种都用水、反复漏下去，二排没接住会**渗到发泡回填材料里、时间长了发臭**（向禹霖）。

**另一种方案**：硬装全部结束，**用胶带封死缝隙 + 抽水机抽干厕所的水**再做。

**柜子下面**：面积不大、省不了多少，**建议一块做了**（厕所以外美缝主要修饰作用）。

### 材质难度阶梯
