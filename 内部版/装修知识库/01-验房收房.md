# 验房收房

> 装修第一步。验房是唯一一次能在装修前发现并让开发商整改的机会，**别急着收房**。

## ✅ 一句话结论

- 🔴 **卫生间空鼓 0 底线**；电梯厅墙砖是重灾区，拐角/踢脚线最多。
- 🟡 **至少验 2 次**：第一次装修公司免费验（不仔细），第二次请专业验房师。
- 🟡 **门框下边没灌砂浆是交付标准**（三边灌浆、下边不灌），半包注浆即可。
- 🔴 **收房费用 125 户型约 5000+ 元**：物业费 + 押金 2000 + 管理费 + 垃圾清运。
- 🟡 **物业费从 8.1 起算不合理**，应争取从次月算；收房礼品可争取。
- 🟡 **空鼓修复开发商提"换砖"多是拖延**，明确要求注浆即可。
- 🟡 **房产证可线上申领**，没交房/贷款没还完也能领。
- 🟢 **顶上保温层表面是水泥灰**（非腻子，交付即如此）。

## ⚠️ 最关键避坑

- ❌ **别急着收房** — 发现问题要开发商整改，收房后责任难说清（有业主因玻璃问题拒收）。
- ❌ **只验一次就收房** — 至少验 2 次，请专业验房师。
- ❌ **忽视空鼓复验** — 电梯厅墙面大面积空鼓集中在墙根，收房前务必复验。
- ❌ **被"换砖"拖延带偏** — 明确要求注浆（打孔修复，看不出痕迹）。
- ❌ **物业费从 8.1 起算** — 应向物业提异议（寄拒收通知书）；整改期间可拒交（见 [[14-小区与维权]]）。

## ⏰ 最迟决策时点

- **收房前**完成全部验房 + 问题整改清单确认。
- 验房发现的问题，**当场找物业打负责人电话、盯着修**；后续问题统一批量修。
- **收房时**确认费用构成（物业费起算点、押金、垃圾清运费），别稀里糊涂交钱。

## 🧭 空鼓检查（重中之重）

- **卫生间 0 空鼓**（底线）；其他位置问题不大，补了最好。
- **自检方法**：拿小棍敲、听声音（空鼓声脆）。
- **解决流程**：切割开 → 填充水泥 → 表面抹平。
- 验收工具：**空鼓锤**；专业验房师比免费的仔细。

| 区域 | 要求 |
|---|---|
| 卫生间 | **0 空鼓** |
| 电梯厅 | 墙砖空鼓重灾区（"写满了空"），上方瓷砖空鼓要修 |
| 拐角 / 踢脚线 | 空鼓最多，重点查 |

> 参考个案：kaka 家"房子里面硬是没有一个空鼓，玻璃没有一处划痕"；Lansun 叫湖南设计院验，"还是专业一些"。

## 🧭 其他质量问题（照着查）

- **天花板裂缝**：可能是保温层导致，铲了墙灰可能没问题。
- **窗户异响**：合页问题，让师傅调一下即可。
- **玻璃**：检查划痕、气泡；有业主因玻璃问题拒绝收房（详见 [[14-小区与维权]]）。
- **顶上保温层**：物业/工程部确认表面是**水泥灰**（王超，不是腻子，交付即如此）。
- **门框**：三边灌浆、下边不灌是**交付标准**，后期半包注浆处理即可。

## 🧭 收房流程与费用

**流程**：收房程序简单"反正就是交钱"；自装签自己，装修公司装的把对接人叫上（向禹霖🌲 实测）。

**费用**（125 户型合计 **5000 多元**）：

| 项目 | 金额 |
|---|---|
| 半年物业费 | 从 **8.1 起算** |
| 装修押金 | **2000 元** |
| 装修管理费 | — |
| 小件垃圾清运费 | — |

- 物业费减免政策**还没正式签署**，只能顺延。
- **物业费从 8.1 起算不合理**：法律角度应从次月（9 月）收；寄拒收通知书物业说没收到、EMS 单号拒不承认。
- **130 户型面积比 125 小、物业费反而更高**（A：文吐槽）；"晚收房送半年物业费"（ni-yo）。

## 🧭 整改现状（要有心理预期）

- **整改速度慢**（一个星期只动几个空鼓）；管家每隔两三天问一次，不主动告知进度。
- **快修队**在集中交房期间可边验边修。
- 空鼓整改半个多月还没好的案例（Y，8-19）；"搞了空鼓才走"（可可君）。
- 电梯厅墙面大面积空鼓，业主只能周末找物业，整改了这么久还没改（婷🐳）；**物业人力少招不到人**。
- 修复经验：物业修瓷砖技术菜时**态度要硬一点**才能推动解决（见 [[05-防水与贴砖]] 瓷砖修复经验）。

## 🧭 房产证线上申领

- **方法**：微信公众号「**长沙不动产登记**」→ 办事大厅 → 线上申办 → 纸质证书申领。
- **无需收房**：没交房 / 贷款没还完也能领（范子超：没收房不影响房子是你的）。
- ⚠️ **电子证照判断**：只有一张电子证照 = **预告登记**那张，正式登记的证书还没办好（PatientZero 科普）；办好后才有纸质证书。Carl 案例：能查电子证照但无纸质证书 = 正式登记未办好。
- **实测效率高**：昨天申请今早就到（ni-yo / 👻）。
