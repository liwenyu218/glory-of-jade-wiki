# 智能家居

> 智能家居不必一步到位——**先搞智能开关，后面再加传感器**。全屋 WiFi 用 mesh 比 AP 省。

## ✅ 一句话结论

- 🔴 **全屋 WiFi 选 mesh 别上 AP**：每间房留网线、电视柜留两个网口，客厅 + 主卧放 2-3 个路由组有线 Mesh。网线超六类足够。
- 🔴 **路由器选中兴（便宜）/华为（好用），别买小米路由器**（爱断网）。AP 又贵又难检修、面板会熏黑墙面、要加 POE。
- 🔴 **智能开关必须留零线**（水电交底时定）：单火易出故障；接线的比带电池无线的好用；开关 + 智能灯单控要**转无线**。
- 🔴 **全屋智能价差极大：米家 3K~1.5 万 / Aqara 略贵更灵敏 / 华为 4 万多 / 小米之家方案 5000+**；叫多家出方案再比价。
- 🔴 **轻智能（灯 + 窗帘 + 网络）约 1.3 万**；自装米家约 3K。厨房不做防水的兜底 = **水浸传感器 + 智能水阀**。
- 🟡 **门禁接不了米家**（独立系统、网络安全考虑），KNX 可试但费用是米家几倍；面板位置要预留电源。
- 🟡 **扫地机器人**：柔光砖配滚筒（G30pro/p30pro 约 4500），亮光砖配圆盘（p20max 约 3200）。
- 🟢 **监控/电动窗帘**：监控水电阶段预留线路；电动窗帘留插座自己买自己装，轨道随全屋智能一起量。

## ⚠️ 最关键避坑

- ❌ **一上来就全屋智能大件** — 大件（空调等）别用小米，小件可以。
- ❌ **WiFi 布线没留网口** — 电视柜最好留两个网线口（有线 mesh 组网用）。
- ❌ **智能窗帘选错** — 有的可手动拉、有的不可，看型号；要无极调节/半开的更好。
- ❌ **智能开关走单火** — 单火易出故障，要留 0 线（零线）。
- ❌ **智能开关 + 智能灯不转无线** — 单控要转无线控制灯，否则开关一摁智能灯就离线。
- ❌ **柜子灯带没预埋** — 要做灯带（接智能）就型材预埋，木工阶段买。
- ❌ **面板位置忘留电源** — Shane"忘记留电源了，留插座了"。

## ⏰ 最迟决策时点

- **水电阶段**：确定智能开关点位（开关留零线、传感器留零火线）、WiFi 网口位置、VRF 网关需求（开槽前）、监控/室外摄像头留线、电动窗帘留插座。
- **柜子灯带/型材预埋**：木工阶段买、装。
- **弱电箱位置**：移位后入户光纤要重新拉，提前定。
- **木工预埋窗帘轨道前**：就要定电动窗帘轨道（网上买先问清宽度）。

## 🧭 全屋 WiFi

### 方案对比

| 维度 | AP（吸顶/面板） | Mesh 路由 |
|------|----------------|-----------|
| 价格 | 贵（两三千 + POE 供电） | 便宜 |
| 美观 | 漂亮高级感（藏吊顶/面板） | 路由器外露 |
| 检修 | 坏了爬顶上检修 | 随手可换 |
| 覆盖 | 覆盖不到卫生间 | 3 个路由组网"基本无敌" |
| 适用 | 大平层/别墅/跨层 | 普通户型足够 |

> "AP 又贵又不好用又难检修，优点就是漂亮高级感。" —— 道法自然

- **acap vs mesh**：多数选 **mesh**（省钱）；acap"美观但贵，两三千"、"不吸顶拉完不如 mesh"。
- **面板 AP 会熏黑墙面**（散热，叫 77 问"是热还是脏"）；AP 要加 POE、小弱电箱不够用（👻）。
- **Miya 方案**：自己设计 2 个 AP 放吊顶（餐厅 + 主卧），AP 和中央空调一起做。

- **网线规格**：**超六类足够**（犯困蟹皇堡、道法自然：到 6G 时代优势大、万兆网速）；**六类线 + 光纤一起埋**（木瓜朋友建议：六类管当下、光纤支援未来）。

### 布线要求

- 电视柜最好留两个网线口（有线 mesh 组网时用）。
- **每个房间一根网线**（好吧）；电竞房 3 个网口（17_D，装修公司不加钱）。
- **弱电箱和主路由之间留 2 根网线**（庆；主路由直接放弱电箱就不用管）。
- **Mesh 组网**：客厅一个 + 主卧一个基本够（👻、Plutor）；多个路由 Mesh 后等于一个 WiFi 自动切换；**有线 Mesh 稳定、无线不稳定**。
- **犯困蟹皇堡决策**：不搞 AP 改**有线 Mesh**（甩一根顶上网线走网关 → 确认网关和路由器放一起即可，单独拉网关线没必要）。
- **FTTR 避坑**：晴茝"上了电信 FTTR 的当"——电信 1000M 宽带硬要带 FTTR 才给（不然只能 300M）。
- **光屿智能**：出智能方案（灯光智能图 PDF），设备网价少 5%、集采优势，但**不做团购、不一起卖材料**。

## 🧭 智能开关

### 零线 / 接线 vs 无线

- **水电交底正常来**：全智能/轻智能都注意**开关留零线**、**传感器位置留零火线**即可（范子超）；"反正把零线留好备用"（犯困蟹皇堡）。
- 🔴 **不要走单火的**，要走 **0 线（零线）**——单火容易出故障（17_D"我也是听说单火的容易出故障"）。
- **接线的智能开关更好用**："带电池的（无线）寿命短，不好用"；"一般常规的需要给电源，效果和使用寿命都好很多"（犯困蟹皇堡代答智能商家）。
- **智能开关 + 智能灯**：单控的也要**转无线去控制灯**，不然开关一摁智能灯就离线了（庆）。
- **双控**：多预留双控线，万一换普通开关还能用；不建议一个智能一个普通走双控线。
- **基本开关可自己 DIY**，场景/联动就得设计（犯困蟹皇堡）。

### 型号

- s5 换 s5pro（磨砂玻璃），和 e3pro 搭配，约 143 元。

## 🧭 智能窗帘

- 有的可手动拉、有的不可，看型号。
- "钱到位"可实现无极调节/半开（语音喊停某位置）；普通只能全开/全关。
- **留插座自己买自己装**（商家有安装服务）或智能插座 + 电动轨道自组；**轨道随全屋智能一起量、按确认米数收费**（领普·米家）。
- **卧室双轨（布 + 纱）、客厅/书房单轨**，厨房不做电动；**客厅窗框内双轨宽度不够**（窗宽超 2200 即挤）→ 吊顶预留轨道槽（见 [[12-家具与软装]]）。
- ⚠️ **木工预埋轨道前就要定**、网上买轨道先问清宽度。

## 🧭 门禁接入

> 范子超问"门禁大屏（梯控/单元楼门禁/单元楼视频/接听）怎么接入米家"，犯困蟹皇堡代问智能商家"彭程"。

- **门禁接不了米家**：门禁属于**另外一个独立系统**；**公共空间系统一般不建议接入家庭私人系统，主要考虑网络安全**（"你想物业把你家摄像头打开吗"）。
- **用 KNX 可以一试**，米家不行；但要做实验，**KNX 费用是米家的几倍**（因为是**有线智能**）。
- 有线智能**单机离线状态下也能用**（无线涉及网络安全）。
- 若系统支持米家通讯协议可介入（彭程），但一般门禁系统都是独立的。

### 面板与智能锁

- 开发商标配门禁面板实测 **17.9×11.7×2.5cm**、很轻很塑料；可换 **colmo 智慧大屏**（需转换器约 500 元，连米家/华为），常见装法**装玄关柜里面**。
- ⚠️ **面板位置要留电源**（Shane"忘记留电源了，留插座了"）。

## 🧭 柜子灯带 & 型材预埋

- 柜子灯带要不要接智能：**可接可不接**；不需要调光调色的正常做省钱（范子超）；但不接就没法一键关灯（关门关灯/开门开灯）。
- 🔴 **要做灯带（接智能）就型材预埋**：**木工阶段买、装灯带和型材**（范子超"木工阶段可以装灯带和型材"；犯困蟹皇堡"还有预埋"）。

## 🧭 监控 / 可视门铃

- 一梯一户觉得安全可只加**可视门铃**（看门外）；门锁本身可能带该功能（庆）。
- **监控回路**：项目经建建议监控可与**冰箱一路**（反正日常不关）。
- 全国少先队代表：之前用 360 监控不智能、存储贵。
- 室外摄像头：水电阶段要在门口上面**留线**（Miya 提醒）——电梯厅/室外**水电阶段预留线路、定位置**，后期买嵌入式（要打孔）；装修期买电池款吓唬人即可、不用提前买。
- 电梯厅装监控：线可**从灯线延长**接（范子超）。
