## 一、全屋组网大讨论（AP vs Mesh，今日重头戏）

### 🔴 核心结论：Mesh 路由够用，别上 AP

> "AP 又贵又不好用又难检修，优点就是漂亮高级感。" —— 道法自然

- **AP（吸顶/面板）缺点**（庆、👻、道法自然等）：面板 AP 有概率**熏黑墙面**（散热）、AP 贵、坏了要爬顶上检修、要加 POE 供电（小弱电箱不够用）、覆盖不到卫生间。
- **Mesh 组网**：埋好网线放 2-3 个路由组网"基本无敌"（一米阳光）；客厅一个 + 主卧一个基本够（👻、Plutor）；多个路由 Mesh 后等于一个 WiFi 自动切换（一米阳光问、庆答）。
- **犯困蟹皇堡最终决策**：不搞 AP，改**有线 Mesh**（打电话问设计师：甩一根顶上网线走网关→后确认网关和路由器放一起即可，单独拉网关线没必要）。
- **AP 适用场景**：大平层 / 别墅 / 跨层才需要（道法自然、Plutor、一米阳光）。

### 🟡 网线标准与布局

| 话题 | 结论 |
|------|------|
| 网线规格 | **超六类足够**（犯困蟹皇堡、道法自然：到 6G 时代优势大、万兆网速）；木瓜"六类够了"；**六类线 + 光纤一起埋**（木瓜朋友建议：六类管当下、光纤支援未来） |
| 每房间 | 每个房间留一根网线不会有错（好吧）；卧室路由器藏起来接网线、**必须有线**（👻） |
| 电竞房 | 3 个网口（17_D，装修公司不加钱）；插座要加钱（全屋 80+ 插座） |
| 弱电箱 | Mesh 记得**弱电箱和主路由之间留 2 根网线**；主路由直接放弱电箱就不用管（庆） |
| 路由器品牌 | 中兴的便宜（庆）、华为好用（Carl）；**别买小米路由器**（Carl：爱断网） |
| 有线 vs 无线 | 有线 Mesh 稳定、无线不稳定（群共识） |
