### 🔴 封窗知识科普（犯困蟹皇堡扫盲）

| 维度 | 结论 |
| ---- | ---- |
| 轨道数 | **轨道数越多越稳**：三轨=一玻璃一轨+一纱窗一轨+一玻璃一轨；五轨=双轨上玻璃+单轨上纱窗+双轨上玻璃；玻璃几十斤，轨道越多承重/顺滑越好 |
| 断桥 | 断桥=隔音隔热；**断桥 > 非断桥**（非断桥没有断桥的隔音隔热效果） |
| 综合排名（美观省空间） | 推拉断桥 > 平开 > 推拉非断桥 |
| 综合排名（传统隔音隔热） | 平开 > 推拉断桥 > 推拉非断桥 |
| 三轨劣势 | 更容易风吹雨打刮水进来、密封性没那么好 |

- **物业要求只能做推拉窗**；平开窗隔音更好但更占空间（打开时）
- 犯困蟹皇堡计划：做科普视频/文件扫盲、联系老板搭**样板间**、出最简单明了的方案和示意图
- 王妈的小阳台封窗也交给小狗哥安排

### 🟡 Z字封窗与香槟色问题

## 三、地面找平 / 贴砖 / 地暖（🟡 主群）

### 🟡 地面三个高度怎么贴砖

- 相睎家通水后水管渗水、地面有三个高度，问大家怎么贴瓷砖
- **找平到最高面统一**（"找平到1的高度""找平到最高的那个面"）；砂浆变厚要加材料钱（不多）
- 范子超打算 **8cm 厚贴瓷砖**（瓷砖+砂浆），觉得窗台石不好看直接厚贴过去
- 装修公司建议相睎家窗台石收口（收口都得窗台石）；地面直接铺管然后水泥砂浆找平贴砖

### 🟡 边户做地暖会超出窗框

- **边户做地暖以后确实是大问题**（Real）：会超出窗框，牵涉后期玻璃爆了更换
- 叫77不叫琪琪：工厂和地暖商家算的高度最后做出来差不多跟门框齐平
- Real 建议：装地暖最好装**很薄的地暖（干式地暖）**就好一点
- **瓷砖薄贴**：瓷砖薄贴厚贴高度差不了很多，但**薄贴要精找平**；有地暖的话装修公司基本都会给薄贴（标配）；瓷砖胶有柔性的加地暖不容易开裂

### 🟢 阴阳角 / 腻子 / 窗台石

- 相睎问全房阴阳角能否取消、是否只刮两遍腻子（彭艳辉：做海棠角，但那是瓷砖的，墙面不一样）
