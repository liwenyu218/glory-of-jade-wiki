# 智能家居

> 智能家居不必一步到位——**先搞智能开关，后面再加传感器**。全屋WiFi用mesh比acap省。

## ✅ 一句话结论

- 🔴 **全屋WiFi选 mesh，不必上 AP**：埋好网线放 2-3 个路由组 Mesh 即可；AP（吸顶/面板）贵、检修难、面板可能熏黑墙面（2026-08-19）。
- 🟢 **网线选超六类足够**（6G 时代优势明显）；六类线+光纤一起埋更稳；部分品牌路由器断网反馈较多（2026-08-19）。
- 🟢 **先搞智能开关，后面再加传感器**（传感器多是电池的，好加）。
- 🟢 **买VRF网关**可把中央空调接入智能生态（详见 [[07-中央空调]]）。
- 🔴 **智能开关要留零线**：水电交底时开关留零线、传感器位置留零火线（2026-08-18）。
- 🟢 **轻智能最小配置（2026-08-27）**：**留零线 + 每个房间留网线 + 客厅留两个**，做灯/空调/人体存在传感器即可。
- 🟡 **接线的智能开关比无线（带电池）好用**：带电池寿命短（2026-08-18）。
- 🟡 **门禁接不了米家**：门禁系统独立（网络安全），KNX可试但不划算（2026-08-18）。
- 🟡 **门禁面板（2026-08-29）**：开发商标配面板实测 **17.9 × 11.7 × 2.5cm**、塑料感较强；**可换智慧大屏**（需确认接口与电源）；常见装法**装玄关柜里面**；⚠️ **面板位置要预留电源**（有业主忘记留电源只留插座）。
- 🔴 **智能锁改密码（2026-08-30，防工人进房）**：工人能进房说明**初始密码已泄漏**——下**智能锁 APP 连上锁可改密码/添加临时密码**，用**回形针戳复位孔**；或跟物业要回形针改密码；该锁支持**人脸识别/指纹/密码/刷卡**。
- 🔴 **全屋智能两大方案（2026-08-21）**：**小米 / 欧瑞博**；欧瑞博做**集成**——把空调、地暖、新风集中到一个模块，中央控制系统大屏控制，压缩机采用松下。
- 🟡 **自装米家方案（2026-08-21）**：自己买设备自己做，窗帘包安装，自装加窗帘轨道约 **3K 左右**；水电阶段**轻智能留零线、窗帘留插座**。
- 🟡 **全屋智能选型渠道（2026-08-24）**：建材商场（观沙岭）有**领普和易来实体店**（顺便看电器家具）；**大头是灯具、窗帘电机、网络，全做约一万出头**；叫多家出方案再比价。
- 🔴 **全屋智能各家方案对比（2026-08-31）**：有业主准备订**小米全屋智能**（与某装修公司合作）；有业主**已定小区团购**（小米+某灯具品牌，订金 600）：灯+3 智能窗帘+3 防漏水+1 防天然气泄漏+1 自动关水阀门；有业主交 50% 后想退；有套餐仅 1600 只覆盖主卧客厅。
- 🟢 **感应灯（2026-08-31）**：厕所/厨房/衣帽间建议用感应灯。
- 🔴 **扫地机器人选购（2026-09-01）**：**柔光砖配滚筒、亮光砖配圆盘**（圆盘刮地板）；柔光砖推荐 G30pro/p30pro、非柔光砖 p20max；有行业背景者提示**好牌子多为 OEM/ODM、最出故障的是软件不是硬件**、更新换代快；**家电越往后越便宜，不急着用可等**。
- 🟡 **监控预留（2026-09-01）**：电梯厅/室外监控**水电阶段预留线路**、确定位置，后期买**嵌入式**的；要打个孔（不然线露外面被扒）；**监控不用提前买**，装修期买电池款放那吓唬人即可。
- 🟡 **智能生态选择（2026-09-01）**：**蓝牙 mesh 2.0 + HA** 比某生态选择多、单品便宜、能接 Apple home（Siri 控灯实测无延迟）；**原生某生态场景互动最合适**；某品牌智能屏**鸡肋、发热严重**，不如小爱音箱；该屏可当网关；**aqara S1 屏 900 多、领普屏幕开关 149**。
- 🔴 **轻智能报价参考（2026-09-02）**：有业主"灯具（某品牌）+窗帘+2000 多网 **报了 3w 多**（房间布帘还自购）"觉得不正常；**有邻居做下来才 1.3w**；建议别急、等邻居作业抄作业；⚠️ 智能报价水分大。
- 🟢 **电动窗帘 DIY（2026-09-02）**：**留插座（充电口）自己买自己装**即可，商家有安装服务；**智能插座 + 电动轨道**自组更划算；大主卧玻璃浴室建议电动窗帘。

- 🟡 **小米全屋智能/床垫联系渠道（2026-09-04）**：群内有业主可对接小米全屋智能工作人员（**七八户已定**）；同一渠道可询品牌床垫（梦百合）联系方式。
- 🔴 **水浸传感器 + 智能水阀（2026-09-06）**：**厨房不做防水的低成本兜底**——厨房装**水浸传感器 + 智能水阀**，漏水自动报警、自动关阀（呼应"厨房无地漏防水做不做"讨论）；有业主分享**「水浸卫士 + 机械手」安装教程**（水位感应关阀）；适合在水槽下方预留电源/位。
- 🟢 **扫地机器人 + 柔光砖（2026-09-06）**：有业主因柔光砖**需给扫地机加预算**（延续"柔光砖配滚筒"结论）；不急着用可等大促。

- 🔴 **电动窗帘轨道预埋（2026-09-08）**：窗帘轨道可**随全屋智能一起**——水电定位时上门量、**按确认的轨道米数收费**；卧室全景舱**双轨（布+纱）**、客厅书房**单轨**（书房需投影/游戏才建议双轨）；**木工预埋轨道前先定好**并留尺寸；⚠️ **客厅窗框内做双轨宽度可能不够**（有案例客厅窗宽超 2200）→ **吊顶预留轨道槽**；预算 3000 内（电机+轨道）够做。
- 🟢 **弱电箱移位/装维警惕（2026-09-08）**：弱电箱移位**入户光纤需重新拉**；有业主被**同一人多个微信号添加**（疑似装维人员推业务）→ 走正规对接人、别乱通过。

## ⚠️ 最关键避坑

- ❌ **一上来就全屋智能大件** — 大件（空调等）别用小米，小件可以。
- ❌ **WiFi布线没留网口** — 电视柜最好留两个网线口（有线mesh组网用）。
- ❌ **智能窗帘选错** — 有的可手动拉、有的不可，看型号；要无极调节/半开的更好。
- ❌ **智能开关走单火** — 单火易出故障，要留0线（零线）（2026-08-18）。
- ❌ **智能开关+智能灯不转无线** — 单控要转无线控制灯，否则开关一摁智能灯就离线（2026-08-18）。
- ❌ **柜子灯带没预埋** — 要做灯带（接智能）就型材预埋，木工阶段买（2026-08-18）。

## ⏰ 最迟决策时点

- **水电阶段**：确定智能开关点位、WiFi网口位置、VRF网关需求（开槽前）。
- **开关留零线/传感器留零火线**：水电交底时就要规划好（2026-08-18）。
- **柜子灯带/型材预埋**：木工阶段买、装（2026-08-18）。

## 🧭 全屋WiFi

| 方案 | 价格 | 来源 |
|---|---|---|
| 日照金山子母路由（一子一母） | 1499元（PDD 1399） | 业主反馈 |
| 加一个子路由 | 700+ | 业主反馈 |
| 中兴问天7200pro+晴天5100 | 性价比高 | 业主反馈 |

- **三室户型一子一母基本够用**（客厅+主卧）。
- 电视柜最好留两个网线口（有线mesh组网时用）。
- **acap vs mesh**：多数选**mesh**（省钱）；acap"美观但贵，两三千"。
- 中兴路由器可做小米生态。

### 🔴 AP vs Mesh 结论（2026-08-19）

| 维度 | AP（吸顶/面板） | Mesh 路由 |
|------|----------------|-----------|
| 价格 | 贵（两三千+POE供电） | 便宜 |
| 美观 | 漂亮高级感（藏吊顶/面板） | 路由器外露 |
| 检修 | 坏了爬顶上检修 | 随手可换 |
| 覆盖 | 覆盖不到卫生间 | 3 个路由组网基本满足 |
| 适用 | 大平层/别墅/跨层 | 普通户型足够 |

- **面板 AP 可能熏黑墙面**（散热问题）；AP 需加 POE 供电、弱电箱空间需足够。
- **Mesh 组网**：客厅一个+主卧一个基本够；多个路由 Mesh 后等于一个 WiFi、自动切换；**有线 Mesh 稳定、无线不稳定**。
- **布局要求**：每个房间一根网线；电竞房预留 3 个网口（多数不加钱）；**弱电箱和主路由之间留 2 根网线**（主路由直接放弱电箱更省事）。
- **网线规格**：**超六类足够**（6G 时代优势明显、支持万兆）；六类线+光纤一起埋（六类管当下、光纤支援未来）。
- **FTTR**：部分运营商 1000M 宽带强制搭配 FTTR 设备（否则降速），需注意资费方案。
- **已有业主决策参考**：不装 AP，改用有线 Mesh。

## 🧭 全屋智能方案

### 思路
- **先搞智能开关**，后面再加传感器。
- 智能灯光：可调色温明度。

### 智能窗帘
- 有的可手动拉、有的不可，看型号。
- "钱到位"可实现无极调节/半开；普通只能全开/全关。

### 智能开关型号
- s5换s5pro（磨砂玻璃），和e3pro搭配，约143元。

### 店铺推荐（2026-08-20）
- 多位业主已做全屋智能，有业主分享推荐店铺（已有业主选定，可私聊要店铺信息）。

### 小米 vs 欧瑞博（2026-08-21）
- **欧瑞博**：做集成——把空调、地暖、新风集中到一个模块，中央控制系统大屏控制；别墅项目多；压缩机采用松下。
- **自装米家方案**：自己买设备自己做，窗帘包安装，自装加窗帘轨道约 **3K 左右**。
- **水电预留（轻智能）**：留零线、窗帘留插座。
- **选型渠道（2026-08-24）**：建材商场（观沙岭）有**领普和易来实体店**（顺便看电器家具）；**大头是灯具、窗帘电机、网络，全做约一万出头**；叫多家出方案再比价。

### 智能开关选零线 / 接线 vs 无线（2026-08-18）

- **水电交底正常来**：全智能/轻智能都注意**开关留零线**、**传感器位置留零火线**即可；"反正把零线留好备用"。
- 🔴 **不要走单火的**，要走 **0线（零线）**——单火容易出故障。
- **接线的智能开关更好用**："带电池的（无线）寿命短，不好用"；"一般常规的需要给电源，效果和使用寿命都好很多"。
- **智能开关+智能灯**：单控的也要**转无线去控制灯**，不然开关一摁智能灯就离线。
- **双控**：多预留双控线，万一换普通开关还能用；不建议一个智能一个普通走双控线。
- **基本开关可自己DIY**，场景/联动就得设计。
- 智能开关价位参考：小米全屋智能 **126平 7000 不贵**，加安装带调试 **1 万以下**。

## 🧭 监控 / 可视门铃（2026-08-20）

- 一梯一户觉得安全可只加**可视门铃**（看门外）；**门锁本身可能带该功能**。
- **监控回路**：监控可与**冰箱一路**（反正日常不关）。
- ⚠️ 部分品牌监控不智能、存储贵。
- **室外摄像头**：水电阶段要在门口上面**留线**。

## 🧭 门禁接入（2026-08-18，🔴 重要）

- **门禁接不了米家**：门禁属于**另外一个独立系统**；**公共空间系统一般不建议接入家庭私人系统，主要考虑网络安全**。
- **用 KNX 可以一试**，米家不行；但要做实验，**KNX 费用是米家的几倍**（因为是**有线智能**）。
- 有线智能**单机离线状态下也能用**（无线涉及网络安全）。
- 若系统支持米家通讯协议可介入，但一般门禁系统都是独立的。

## 🧭 柜子灯带 & 型材预埋（2026-08-18）

- 柜子灯带要不要接智能：**可接可不接**；不需要调光调色的正常做省钱；但不接就没法一键关灯（关门关灯/开门开灯）。
- 🔴 **要做灯带（接智能）就型材预埋**：**木工阶段买、装灯带和型材**。

## 🧭 智能灯光

- 有业主推荐智能灯光方案（小米生态），灯光/开关方案细致。
- **调试服务费一般1000、上门两次**，比其他按总价百分比收服务费性价比高。

## 🧭 中央空调接入

- 买 **VRF 网关**（约800-1000元）可把空调接入智能生态。
- 可选华为或小米生态。

### 智能家居师傅推荐

### 智能生态
- 有全屋智能案例；华为/小米生态可选。

### 扫地机器人 / 监控 / 智能生态（2026-09-01）
- **扫地机器人**：柔光砖配**滚筒**、亮光砖配**圆盘**（圆盘刮地板）；柔光砖推荐 G30pro/p30pro、非柔光砖 p20max；某品牌 4K 多（圆盘）；p20max 3200、p30pro 4500；另一款 3699。
- **行业背景**：有业主有跨境卖扫地机器人经验，研发厂做某头部品牌；**好一点的基本都是 OEM/ODM，最出故障的不是硬件是软件**；很卷、更新换代快；**家电越往后越便宜，不急着用可等**。
- **监控**：电梯厅/室外监控**水电阶段预留线路**、后期买**嵌入式**；要打个孔（门上面是承重、外面看着丑，可买带电池的）；**监控不用提前买**，装修期买电池款放那吓唬人。
- **智能生态（两种观点）**：有业主不弄某 ZigBee 生态，换**蓝牙 mesh 2.0 + HA**（比 Aqara 生态选择多、单品便宜、能接 Apple home，Siri 控灯实测无延迟）；另一业主认为场景互动原生某生态最合适、色温亮度调光模块成本高、喜欢某品牌（只能接模块）。
- **某品牌智能屏**：**鸡肋、发热严重**，不如小爱音箱；可直接用带网关的路由器；该屏可当网关（小的内置 mesh 2.0）、可做从网关；小的不行得买大屏、大屏太贵。
- **价格**：aqara S1 智能屏 900 多、领普屏幕开关 149；mesh 路由 600 够；acap 一套 3K、有线 mesh 1K 多；网关两个 500。

### 轻智能报价 & 电动窗帘 DIY（2026-09-02）
- 有业主（143 大主卧玻璃浴室）问窗帘电动还是普通 → 建议电动窗帘。其轻智能"灯具（西顿）+窗帘+2000 多的网报了 3w 多"（房间布帘还自购）→ 觉得不正常。
