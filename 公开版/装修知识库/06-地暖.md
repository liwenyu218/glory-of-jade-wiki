# 地暖

> 地暖是**贴砖/找平前**要决定的前置工程。**多数人不装地暖**，但想装的关键是选锅炉和算高度。

## ✅ 一句话结论

- 🟡 **多数人不装地暖**（"到冬天就热"；地暖+空调要5万+）。
- 🟡 若装，**锅炉选菲斯曼**（多人选），保温板建议**3公分**（绿羽）。
- 🔴 **边户做地暖会超出窗框**，牵涉后期玻璃爆了更换；建议装**干式地暖（很薄）**。
- 🟡 **锅炉 vs 两联供（2026-08-20）**：两联供要两万多还得配热水器（一个一两千），前期贵很多；"冷凝炉地暖+热水就行"。
- 🟡 **地暖找平价格（2026-08-23）**：半包清单约 **40/平**（豆石混水泥沙子）；材料部门报 **55（不带豆石半干）/110（高流自流平）**；**做地暖地面开不了槽，水电走天或切保温板**；**开发商地面无保温层（只有顶面有）**。

- 🟡 **地暖品牌（2026-09-03）**：燃气锅炉多选**菲斯曼**或**威能**；**两联供**（空调外机带制冷+地暖、走电不走燃气）可选美的，预算足上**约克**。
- 🔴 **完工保护清单（2026-09-03，施工方提醒）**：暖气试压 **8 公斤**、地暖试压 **6 公斤**（后期掉压正常、一般不低于 3 公斤）；找平 **1:2:3 加小鹅卵石**（储热导热好）；盘管垫竹模板/大芯板；铺砖后**勿在地面打孔**；木地板用地暖专用防潮膜；**分集水器处贴砖不超过四边内框**。
- 🔴 **地暖完成高度（2026-09-03）**：湿式地暖约 **7cm**+砖约 1cm；**窗户离地仅 9cm 的户型做完必超窗框** → **免回填地暖/瓷砖薄贴/让施工贴薄点**。

- 🔴 **采暖/两联供比价参考（2026-09-04）**：约克两联供 126㎡ 约 **7.6 万**（125㎡/160 外机可砍、180 外机 8.13 万砍 2 千）；采暖炉 80-93㎡ 报价 **1.7-2.3 万**（不同商家差异大）；国产多联机（star5 系）+知名采暖炉 126㎡ 约 **5 万**；进口三管制 160 外机一拖五 + 冷凝炉约 **6 万出头**；⚠️ 询水空调价格**先别暴露房号**（易被锁价）；不同商家同一品牌报价可差很多。
- 🔴 **采暖炉"系列对标"口诀（2026-09-04）**：菲斯曼 **A1JF↔威能 5-X / A1JE↔classic / B1JG↔ECO PRO / B1KF↔ECO PLUS**——先按系列对标再比能耗与价格，避免被型号绕晕。

- 🔴 **地暖找平 38 元/平（2026-09-09）**：有渠道报价 **38 元/平（包工包料）**、"很良心"（成本约 35）；⚠️ **半包公司报 4800 更贵**（仅做客厅）；找平渠道二选一=**半包公司做 或 地暖商家做**。

## ⚠️ 最关键避坑

- ❌ **边户做普通地暖** — 会超窗框、牵涉玻璃更换；装薄型干式地暖+瓷砖薄贴。
- ❌ **保温板用太薄** — 建议3公分（绿羽），太薄保温差。
- ❌ **地暖与贴砖不协调** — 有地暖要瓷砖薄贴（精找平、瓷砖胶柔性不易开裂）。

## ⏰ 最迟决策时点

- **贴砖/找平前**决定是否装地暖、装哪种（薄/厚、地暖/暖气片）。
- 地暖会抬高地面高度，需**工厂+地暖商家算高度**，别等贴砖才发现。

## 🧭 地暖方案选择

### 装不装？
- **多数不装**："到冬天就热"；地暖+空调要5万+。
- 想装的：建议**干式地暖**（很薄），避免超窗框。

### 锅炉对比
| 锅炉 | 评价 |
|---|---|
| 菲斯曼 24KW B1JG | **多人选** |
| 威能 24KW 冷凝型两用炉 | 备选 |
| 仁博（定） | 总造价2万+ |

### 地暖套餐参考（2026-08-20）
- **格力 Star5 一拖六 + 菲斯曼 B1 地暖，合计约 5.4万**（有业主已定）。
- 有业主问**大金团购（空调地暖五万的那种）**。
- **组合套餐案例（2026-08-21）**：有业主刚订完——**中央空调 + 全屋智能 + 生活热水 + 全屋地暖**，磨了**半年多价格**才定（"价格磨了一年"）；"那一套好贵"。

### 地暖 vs 暖气片
- 一半地暖一半暖气片：2万。
- 只客厅做地暖、其他地方暖气片。

## 🧭 边户与高度

- **边户做地暖会超出窗框**，牵涉后期玻璃爆了更换。
- 建议装**很薄的地暖（干式地暖）**。
- 有地暖装修公司基本都给**瓷砖薄贴**（精找平、瓷砖胶柔性不易开裂）。
- **工厂+地暖商家算高度**，最后做出来差不多跟门框齐平。

## 详细记录（历史讨论，可能过时）

> 以下为重构前的原始碎片记录，保留供回溯。核心结论以上方为准。

### 阳台恐高
- 有业主发高层恐高视频：高层客厅要装两个风扇位；收房第一反应要装好纱窗/栏杆。
- 个别楼栋户型更是恐怖；有业主因此**没收房**。

### 地暖报价建议
- 有业主建议：菲斯曼B1JG往1万砍，铺贴按100元/平算，辅材用绿羽。

### 地暖找平（2026-08-23）
- **半包清单价**：地暖找平 **约40/平**（豆石混合水泥沙子一起；水泥沙子会掺水）。
- **材料部门（中联新材料）**：报 **不带豆石半干 约55 / 高流 约110**；半干=泥瓦匠粉粘稠度、高流=糊糊自流平找平。
- **地面开槽**：做地暖时水电走地面**不开槽，切保温板就行**；地面开不了槽 → 半包承诺水电都走天。
- **开发商地面没做保温层，只有顶面有**（有业主以为有保温层可铲掉做地暖，实际没有）。
