# 防水与贴砖

> 泥瓦工程：防水做不好楼下发霉、贴砖不好会掉砖。**防水是重中之重。**

## ✅ 一句话结论

- 🔴 **墙面防水必须撕**（开发商是柔性防水，不撕贴砖会掉砖），标准是"墙刚地柔"。
- 🔴 **卫生间必须做防水**，厨房建议做（有水管漏水风险）。
- 🟡 **回填**：客厅卧室建渣最省钱，厨卫用陶粒/发泡胶。
- 🟡 **瓷砖选佛山砖**，品质好的约60多元/片。
- 🟡 **美缝**：市场约16元/平（普通）；16可上环氧；了解聚脲（卓高）；群内更低约10/平（2026-08-17/18）。
- 🟡 **岩板/石材**：全屋通铺天然石材约1000/平；洞石难清理不实用；岩板可代替砖做地砖。
- 🟡 **金丝绒/糖果釉/天鹅绒**：750×1500金丝绒最低56块/片（二三线）、金牌亚洲100多；糖果釉比柔光砖耐脏、天鹅绒上一代更便宜（2026-08-18）。
- 🟡 **墙固地固（黄墙绿地）存争议（2026-08-20/22）**：防瓷砖空鼓 vs "形象工程、甲醛易超标"；**木地板才必要**（找平水泥不好后期粉化）；装修公司应给选项看业主意愿；**8-22 群内进一步共识：没啥实际作用还有甲醛，最好到油工/开槽后再刷界面剂**；**放样/刷界面剂是"唬人收高价"噱头**，放样 6 元/平慎选。

- 🔴 **美缝全科普（2026-09-03）**：**时机**=卫生间贴完砖、沉降池水干就做（防后续工种用水渗入回填层、久了发臭），或硬装完**封缝+抽水机抽水**再打；**柜子底下面积小、建议一起做**。材料难度：**水泥基填缝（泥工可做、最简）< 环氧彩砂（可自做）< 真瓷胶（开水泡/前五泵弃用）< 聚脲（有毒须请工人）**；⚠️ 聚脲/环氧先做会被后续刷漆刮花 → 美缝普遍放硬装后期。117㎡ 约 **3-4 千~4-5 千**；**半包/全包基本都不包美缝**；熟练自做一天可完工厨卫。
- 🟡 **墙砖范围（2026-09-03）**：厨卫墙面贴砖（可手工砖/腰线）；**客厅不建议贴**（夏天潮、冬天闷）。

- 🟡 **排水设计要点（2026-09-04）**：**同层排水不能做存水弯**（堵了要撬地面处理），**异层排水才做存水弯**；表面看不出有没有做**二次排水**；🔴 厨房污水返味案例（楼上有污水排入楼下厨房管道）→ 处置=**弯管堵上 + 做好防水 + 拍视频留证据**防邻里纠纷；飘窗（含厨房飘窗）防水务必做好。
- 🔴 **厨房防水做不做？（2026-09-06 大讨论）**：两派——**主张做**：不漏则已、漏了难发现（直接漏楼下），漏客厅最后还是漏楼下，不如让水在厨房漏；**主张不做**：厨房**没有地漏**，做了漏水也排不掉（只能漏楼下/客厅），"不带地漏的地方都不做防水"，主流=卫生间+生活阳台做；某装修公司口径：生活阳台+卫生间做、厨房不做（空调外机位做要加钱）。**不做防水的低成本兜底=水浸传感器 + 智能水阀**（漏水自动关阀报警，详见智能家居篇）。
- 🟡 **飘窗拆后卫生间砌墙做防水？两派（2026-09-07）**：拆飘窗后在窗边砌墙（再在墙内侧做防水）为一种做法（监理主张，防漏水到楼下）；另一派（多家装修公司/管家）**不砌墙、直接做防水+放坡**即可；⚠️ 砌墙的主要顾虑=**玻璃日后爆裂难更换**（需拆墙）；折中=只把窗边缝隙做好防水（窄缝可用**小刷子伸进去刷**）、不填墙不砌墙。新砌墙可用**水泥小砖**（见拆改篇），防水工艺不受影响。

## ⚠️ 最关键避坑

- ❌ **墙面防水不撕就贴砖** — 柔性防水会掉砖，标准"墙刚地柔"。
- ❌ **厨卫回填用建渣** — 走管道/落差大用陶粒/发泡胶。
- ❌ **瓷砖空鼓率高** — 贴完要验收（空鼓率＜5%）。
- ❌ **地暖与贴砖不协调** — 有地暖要瓷砖薄贴（精找平）。
- ❌ **美缝不早了解** — 高峰期要排队；早了解团购（市场16/平可上环氧）。

## ⏰ 最迟决策时点

- **贴砖前**：决定通铺还是过门石、瓷砖款式、地暖是否装（地暖要贴砖前定，见 [[06-地暖]]）。
- **防水后、贴砖前**：做闭水试验。

## 🧭 防水要点

### 墙面防水
- **墙面防水必须撕**（柔性防水，撕下来贴砖才会牢），标准"墙刚地柔"（墙面刚性、地面柔性）。

### 卫生间 / 厨房
- **卫生间必须做防水**（没争议）。
- **厨房建议做**（有水管漏水风险）。
- **次卫防水：墙面必须铲、地面可以不铲**。
- 淋浴区墙面防水高度≥1.8米，干区≥1.2米。

### 闭水试验
- 蓄水深度超2厘米，持续48小时，亲自到楼下邻居家检查天花板。

### 墙固地固 / 黄墙绿地（2026-08-20 / 08-22）

| 木地板需要地固：找平水泥不好后期会粉化 | 部分业主观点 |
| 黄墙绿地是形象工程，甲醛还容易超标 | 部分业主观点 |

| 名匠有墙固 | 有业主反馈 |
| **没啥用，最好到油工再搞** | 经验业主观点（8-22） |
| **没做，项目刷了无色墙固；"没啥用还有甲醛"** | 经验业主观点（8-22） |
| **"除了好看，毫无作用"**（特地问过） | 业主观点（8-22） |

**正确工序（8-22）：**
- 顺序 A：**开完槽 → 刷墙固地固 → 找平 → 按底盒 → 水电进场走线**。
- 顺序 B：**砌墙后放样 → 水电开槽 → 清理开槽 → 在开槽处刷界面剂**。
- ⚠️ **先刷墙固再开槽会破坏**（开槽的粉末会破坏墙固）。

**放样 / 刷界面剂（8-22，避坑）：**
- **放样 6 元/平**（若想要可以和装修公司协商）。
- 经验业主：**放样和刷界面剂是"唬人收高价"噱头**，"你不划线也是那么施工的""花里胡哨的，其实一样的，不然咋收高价"。
- 放样/刷界面剂"看着好看"，但对施工结果无实际提升。

### 卫生间吊顶（2026-08-20）
- **铝扣板**：好维护；**硅钙板**：好看但须木工做、要先贴砖；**防水石膏板**：好看。

### 贴砖工艺
- 提前与师傅确认**通铺还是用过门石**。
- 留缝铺贴：墙砖约1.5mm缝，地砖2-3mm缝。
- 厨卫用"**墙压地**"工艺，防水更好。
- 瓦工退场前做完美缝，干透后铺地面保护膜。
- 空鼓率需＜5%（用空鼓锤检查）。

## 🧭 美缝（2026-08-17 / 08-18）

- **市场价**：普通美缝约 **16元/平**；16在外面可上环氧；有商家团购送美容胶。
- **群内更低价（08-18）**：**10左右/平**（有不同档位）。
- **材质**：了解聚脲（卓高）、马贝。
- **地板平缝（2026-08-19）**：**氢化环氧会掉色**；擦洗白刚玉；**聚脲压平缝**（卓高孙师傅）。
- 建议早点了解（"跟拆墙一样高峰期要排队"）。

## 🧭 岩板/石材/莱姆石（2026-08-17）

- 有业主**全屋通铺天然莱姆石**（大理石材）；天然石材约 **1000元/平**。
- **洞石难清理不实用**（真洞石很多孔、难搞卫生）；莱姆石肌理岩板（进口）质感接近。
- 建议：**小面积点缀用石材更真实，岩板可代替砖做地砖**（岩板做地砖效果好）。
- 手工砖约158元起。

## 🧭 回填速查

| 区域 | 回填方式 |
|---|---|
| 客厅/卧室（没水） | 建渣（最省钱） |
| 厨房（落差小） | 水泥通铺，不用回填 |
| 厨房（落差大）/卫生间 | 陶粒/发泡胶（防水） |
| 飘窗 | 建渣；厨房飘窗下沉用发泡胶 |
| 空调外机位坑 | 陶粒 |
| 生活阳台 | 不要填墙渣 |

> "房间用建渣最省钱，厨卫用陶粒或发泡水泥" —— 群友共识

## 🧭 找平（地面）

- **地暖回填 ≠ 找平**：半包师傅说地面不用做找平只要做地暖回填，"就是地暖"。
- 找平比价：4800（客厅地暖+其他普通找平）、8k（某全包公司）、5000（109户型）、6000（125户型）。
- 有地暖装修公司基本都给**瓷砖薄贴**（薄贴要精找平；瓷砖胶有柔性、加地暖不易开裂）。

## 详细记录（历史讨论，可能过时）

> 以下为重构前的原始碎片记录，保留供回溯。核心结论以上方为准。

### 回填分类
- 客厅卧室完全没水回填用建渣；厨房砸完落差小水泥通铺；落差大或卫生间用陶粒/发泡胶。
- 生活阳台不要填墙渣；空调外机位坑用陶粒填。
- 飘窗都有100厚的板子（假飘窗）；回填不建议用钢筋（太重）。

### 瓷砖风格
- 蓝水晶大理石（台面）：适合极简、简约、包豪斯风格。
- 木纹砖：有人字形铺法，也有非人字形。

### 瓷砖修复经验（🟡 2026-08-31）
- 有业主反馈：物业修瓷砖**技术一般**，一块砖修了一个半月才来；**态度强硬后来了修复高手**，处理效果好多了。
- 经验：物业修复拖延/技术差时，**态度要硬一点**才能推动解决。
