# 拆改与结构安全

> 拆改是装修第一坑，也是**唯一涉及房屋安全**的环节。**承重墙红线看这一篇就够了。**

## 🚨 承重墙安全红线（重中之重）

> **承重梁柱不能开槽；承重墙可开竖槽、尽量不开横槽、禁止长横槽；梁可打孔不能开槽；承重柱最好不动。** —— 装修群共识

> 🟡 **承重墙图获取（2026-08-27）**：签字时的户型图/户型改造图会标注承重/非承重墙；**找物业要图 + 工程部上门确认最稳**；**同户型都可能不准，需拿自己家的**。

### 国标底线（GB50327-2001）

| 红线 | 具体标准 |
|---|---|
| 横向开槽 | **严禁超过 300mm（30cm）**，禁止水平贯通槽、斜向槽 |
| 开槽深度 | **≤ 墙厚 1/3**（24cm 墙 = 8cm） |
| 槽距 | 500mm 内禁正反两面同时开槽 |
| 优先方案 | **竖槽（纵槽）破坏远小于横槽**，是承重墙布管优先方案 |
| 竖向主筋 | **不能切**（切横向钢筋影响相对小，竖向更严重） |

- 横槽仅限开关/插座点位极短，需用**钢筋探测仪避开主筋**。
- 边户多为承重墙、水泥砂浆层仅 1.5cm，走水电开槽必露钢筋。

### 一旦切到钢筋的处理流程

1. **先停工** → 2. **做结构鉴定**（别先修补！修补后无法鉴定） → 3. 不能直接水泥糊上 → 4. **要求物业/开发商出书面结构安全鉴定报告** → 5. 必要时报警

## ✅ 一句话结论

- **拆改前先办手续**、**向物业要砸墙图**（每层图不同，别盲信户型图）。
- **拆除团购约900-1000元**，别被报到5000-6000；**口碑推荐：陈师傅（A专业打墙）/ 黄师傅 / 三川源**（2026-08-20）。
- 🟢 **八百库（2026-08-28）**：有业主**砸掉电视墙转角**做八百库（储物间）；砸转角墙需先确认非承重再动。
- **回填**：客厅卧室建渣最省钱，厨卫用陶粒/发泡胶。
- **反地梁不能铲（2026-08-19）**：原计划铲的地面构造，确认是反地梁后必须停手——铲改前先确认地面结构。
- 🟡 **顶部白灰铲不铲（2026-08-29 施工方专业讲解 + 2026-08-30 群内大讨论）**：顶面是**聚丙烯防开裂砂浆层+挂网防开裂底灰**（非保温层/隔音层），作用是防楼板伸缩缝导致后期腻子开裂；**验证方法：喷水试，掉皮（起泡、一块块掉）就要铲，不掉皮不用铲**；主张不铲（施工方/多数装修公司）：除非空鼓锤检测发现空鼓脱层，否则只需扫掉表面浮灰；主张铲（部分业主/工长）：白灰一喷水就掉、后期易掉漆起泡、南方回南天梅雨多住得久建议铲；**已铲除需补救：干透后界面剂+挂网+防开裂底灰**；⚠️ 做**无主灯**可考虑不铲；⚠️ 有工地顶铲到一半师傅铲不动罢工（需换人）；⚠️ 飘窗附近有约20cm宽3cm厚混凝土条铲不动、留3cm高低差需吊顶遮掩。🟡 **8-31 补充**：**无主灯可考虑不铲、主灯建议铲**（后期易掉漆起泡）；有师傅铲顶灰多收 600。🟡 **9-1 价格明细**：**全屋吊顶部分可不铲、非吊顶部分铲**（有业主实测）；铲顶灰价差大——有业主顶灰+阳台 **3150**、125㎡ 铲顶+阳台 **400**、117㎡ **600**、**200**、拆 1600 未铲顶灰；**阳台保温层约 200**；⚠️ 多比价（顶灰价格 200-600 不等）。
- 🔴 **砸墙价格行情（2026-08-29~30）**：109㎡ 约**2100**（有保温层+200）、133㎡ 约**2000**、另一家 2500；8-30 对比：全房拆除（铲墙+防水+保温层）可砍到 **2000**（原报价 3500 不包铲白灰和防水保温层）、拆墙 2000（含次卫/南向卧室/衣帽间三面墙）、砸墙（多砸两墙+阳台保温层）2800、拆墙+铲顶灰 2700；**铲顶灰单独 300~800 元/户**（5 元/平）；**铲阳台保温/铲卫生间防水/砸非承重墙均为加价项，动工前务必谈好**；优质师傅**切割为主、电锤为辅、报价后无增项**。

- 🟡 **砌墙填缝 / 承重墙开槽恢复渠道（2026-09-05）**：施工要点——**砌墙要先填缝、竖着撑才稳**；开槽/填缝找谁处理 → 建议**找社区、让物业管家联系**（物业/开发商有处理渠道），另有施工团队兼做此类小工（详见装修公司主题）；⚠️ 承重墙损坏一律走**停工→结构鉴定→官方修复**流程、勿自行回填。
- 🔴 **主卧门口垛子别砸（2026-09-07，多户亲历）**：图纸上该区域可能空白/标非承重，但实测**与承重墙一体浇筑（含混凝土+钢筋）**——有业主砸开一点见钢筋即停、有业主咨询工程部确认**不能砸**；改门洞做套间的需求只能**视觉弱化（拱形/造型/柜体收口）**解决；⚠️ **每一栋情况不同**，改门洞前先让师傅探墙 + 找物业确认；拆墙/改造开工前务必**现场交底对接**（有业主未现场确认返工多花千元）。

- 🟢 **门垛子拆除实例（2026-09-08）**：次卫防火门处约 **10 公分门垛子**，有业主同位置**已敲**（晒图参考；需先确认非承重/提前与物业确认）。
- 🔴 **外包打孔事故警示（2026-09-08）**：有业主施工打孔**打穿水管**（离水管仅差 5-10 公分、师傅"有点激进"），家中被水淹；**打孔多为装修公司外包**——出问题由**装修公司负责修复**（未获赔偿）；教训：打孔前要求工长/外包报点位、现场紧盯。

## ⚠️ 最关键避坑

- ❌ **拆承重墙/承重柱/构造柱** — 涉及整栋安全，严禁；构造柱与主体一体浇筑
- ❌ **盲信户型图** — 实际结构可能与图纸不符（🔴 部分户型标非承重实际浇筑一体，门洞缩小到79cm需定制、生活阳台改从厨房进）
- ❌ **被报天价拆除费** — 团购900-1000，大户型6000虚高
- ❌ **退场没验收就给钱** — 拆项写进合同、验收合格再给尾款
- ❌ **避雷「今旺拆除」**（🔴 2026-08-20 全群实锤）— 在业主家乱尿、明知承重墙仍砸、坐地起价（铲灰要300）、报价不报；"表面看便宜，只要有增项就巨坑"；原为团购推荐，已撤销

## ⏰ 最迟决策时点

- **拆改前**：办装修手续、向物业要砸墙图、确认哪些不能动。
- **水电开槽前**：定好空调、燃气（见 [[04-水电与燃气]]）。
- **砸墙后立刻叫物业打胶**，否则漏水。

## 🧭 回填与防水速查

### 回填方式
| 区域 | 回填方式 |
|---|---|
| 客厅/卧室（没水） | 建渣（最省钱） |
| 厨房（落差小） | 水泥通铺，不用回填 |
| 厨房（落差大）/卫生间 | 陶粒/发泡胶（防水） |
| 飘窗 | 建渣；厨房飘窗下沉用发泡胶；🟡 **8-31 专业解答**：客厅卧室完全没水用建渣；厨房砸完落差小水泥通铺不用回填；厨房落差大或卫生间用陶粒/发泡胶——**发泡比陶粒好**（陶粒可能有味道） |
| 空调外机位坑 | 陶粒 |
| 生活阳台 | 不要填墙渣 |

### 防水
- **墙面防水必须撕**（开发商柔性防水，不撕贴砖会掉砖），标准"墙刚地柔"。
- 卫生间必须做防水；厨房建议做（有水管漏水风险）。
- **次卫防水：墙面必须铲、地面可以不铲**。

## ⚠️ 施工注意 & 验收

- 🔴 **砸完墙立刻叫物业打胶**（玻璃与墙体缝隙），否则漏水。
- 🔴 建渣先堆家里、统一清运，**别偷运**（划伤公区）。
- 🟡 施工时间限制：早8点前、12-14点、17点后不能作业。
- 🔴 **验收**：没验收不给钱；拆项写进合同；退场前必须验收确认。
- 🟡 **砌墙**：多数装修公司不包拆砌；建议找正规施工方做（外面易出错），价格贵约一倍。

### 🔴 打胶时机（2026-08-18）

> 核心："厨房沿着玻璃要砌墙的话，记得找物业窗框打胶。**打胶最晚节点在拆墙清理完垃圾、砌墙之前**，空档期估计就半天。"

- **飘窗砸完**应**立刻**给窗框下半部分打胶（有业主就忘了，砸完直接砌墙）。
- **最佳做法**：砸完飘窗贴保护膜，**最后再打胶**；砌墙部分有担心就**提前打胶**。
- **补救措施**：里面做好防水 + 台面做好封闭 + 窗框外侧已有胶，基本不太会漏水；担心的就**内外都打胶**。
- 已砌墙的**不用纠结玻璃没打胶**（墙和玻璃接缝的胶就不是玻璃的打胶了，外面都打满防水胶）。
- ⚠️ **飘窗拆后要立马喊打胶师傅**：贴了玻璃保护膜后师傅不好打，要撕膜、擦不干胶印再打，可能不好看。
- ⚠️ **打胶师傅有排期**：提前约，否则等物业排期可能**至少一星期不能施工**。
- 窗框胶：同色找物业打；墙后面看不到自己打也可以。
- 🟢 **拆砌墙自理（2026-08-18）**：有全包业主反映装修公司"包砌墙很贵"让业主外面自己找（拆改赚不到钱）；**外面找可省一半**。

## 详细记录（历史讨论，可能过时）

> 以下为重构前的原始碎片记录，保留供回溯。核心结论以上方为准。

### 保温层厚度争议
- 保温层厚度有 **8cm** 与 **3cm** 两种说法需实测；铲掉两边多16cm空间，但影响保温和隔音。

### 天花板保温层铲除 vs 保留
| 立场 | 理由 |
|---|---|
| 铲除 | 怕乳胶漆开裂，铲掉加高几寸层高 |
| 不铲（吊顶） | 吊顶完全覆盖，不影响隔音保温 |
| 不铲（石膏板封） | 比吊顶便宜、比全铲省事 |
| 不铲（搏一搏） | 开裂再修补 |

- **多数建议不铲**；有家铲多钢筋外露——**建议别动顶面**。

### 🔴 顶部抗裂砂浆层专业讲解（2026-08-29，施工方分享）
> "顶部不是保温层也不是隔音层，是聚丙烯防开裂砂浆层+挂网防开裂底灰。作用：楼板浇筑时有伸缩缝，防止后期刮腻子开裂。"
- **不铲的原因**：就是一层防开裂处理，铲了反而容易后期开裂。
- **正确流程**：水电之后用**空鼓锤检查**，空鼓、脱层才铲；没有空鼓不用动。
- **表面浮灰必须去掉**：即使不铲也要扫掉抗裂砂浆表面浮灰，检查排除不能省略。
- **已铲除的补救**：干透后刷**界面剂+挂网+防开裂底灰**再做后续工序。
- **飘窗附近**：临近飘窗处有约 **20cm宽、3cm厚混凝土条**，铲不动，会留 **3cm 高低差需吊顶遮掩**。
- **补充**：顶面处理多为挂网后做的砂浆层（含纤维材料），非与楼板一体浇筑；铲除耗时耗力耗钱，工程方与设计方均不建议铲。

### 🔴 顶灰铲不铲大讨论（2026-08-30）

- **主张铲**：工长说"要铲，一喷水一块块掉"；那层白灰不是保温层；顶上还有一层保温层，不铲到挂网即可，很薄；后期很容易掉漆；南方回南天梅雨季多、房子住得久，一定要铲（两位工长都坚持）。
- **主张不铲/看情况**：顶面是防开裂砂浆层，做了实验（喷水）没起泡就不用铲；"开发商做还是做的抗裂砂浆层，只是可能有些地方手艺不好"；设计师和打墙师傅沟通的可以不用铲；多数装修公司工长说不用铲。
- **现实案例**：有装修公司工地 8 楼顶铲到一半师傅铲不动拒绝罢工、换了好几波人去铲；有业主"一直说保温层不需要铲、项目管家也没让铲"但当晚失眠纠结。
- **价格**：铲顶灰 300 / 400（5 元一平）/ 600 / 800 元不等；全房拆除（铲墙+防水+卫生间保温层）砍到 2000 元；拆墙+铲顶灰 2700 元。
- **结论**："跟小马过河一样"——自家情况喷水验证，掉皮就铲、不掉皮可不铲。

### 飘窗回填专业解答（2026-08-31）
- 客厅卧室完全没水用**建渣**；厨房砸完落差小**水泥通铺不用回填**；厨房砸完落差大或卫生间防水**用陶粒/发泡胶**。
- 陶粒还是发泡胶：**发泡好一点，陶粒可能有点味道**。

### 部分户型承重墙标注不符（🔴 2026-08-24）
- **问题**：购房合同图纸（纸质）标**非承重**，但**拆除时看到混凝土结构（钢筋）**；实际是工程一体浇筑过去；**117公卫 / 125客厅次卧 / 125主卧门垛**的承重墙标注不正确。
- **后果**：门洞只能缩小到 **79cm**（80都敲不出，需**定制门**）；厕所通生活阳台不能全拆，**从厨房进阳台**；生活阳台要改方案。
- **维权**：可**要求开发商赔偿**；**向住建部门举报**（"只要图纸和现实对不上就能举报"）。
- **经验**：**拆除要请专业的，不能硬来，图纸不可信**；承重的拆出来没有这么平整；和承重墙转弯的地方要特别注意。

### 水电横平竖直 vs 点对点
- 横平竖直=要在梁上打孔，影响整栋安全；建议**点对点**。

### 空调孔位问题
- 某栋**只预留1个孔**，其他栋3个；预埋孔位置不对、不够用；工程部踢皮球要地产决定；建议画好水电图+打孔需求一次性审核。
