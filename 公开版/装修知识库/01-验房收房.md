# 验房收房

> 装修第一步。验房是唯一一次能在装修前发现并让开发商整改的机会，**别急着收房**。

## ✅ 一句话结论

- 🔴 **卫生间不能有一处空鼓（底线）；电梯厅墙砖是空鼓重灾区**；拐角、踢脚线处空鼓最多。
- 🟡 **验 2-3 次**：第一次装修公司免费验（不太仔细），第二次请专业验房师。"免费的没有花钱的仔细"。
- 🟡 门框下边没灌水泥砂浆是**交付标准**（三边灌浆、下边不灌），后期半包注浆处理即可。
- 🔴 **收房费用（125 户型约 5000+ 元）**：半年物业费+装修押金 2000+装修管理费+小件垃圾清运费（2026-08-19）。
- 🟡 **物业费起算时点可提出异议**：开发商赠送礼品（戴森吹风机/华为平板/电炖锅等）可争取；中介买房提成可要求返点（2026-08-19）。
- 🟡 **电梯厅墙面大面积空鼓（2026-08-21）**：空鼓多集中在墙根；收房前要复验；若开发商提"换砖"，本质是拖延让你选注浆（注浆即打孔修复，看不出痕迹）。
- 🟡 **房产证可线上申领（2026-08-22）**：微信公众号"长沙不动产登记"→办事大厅→线上申办→纸质证书申领；**没交房/贷款没还完也能领**；⚠️ 只有一张电子证照=预告登记（正式证书未办好），办好后才有纸质证书。

## ⚠️ 最关键避坑

- ❌ **别急着收房**——验房发现问题要开发商整改，收房后责任难说清。
- ❌ **只验一次就收房**——至少验2次，专业验房师更仔细。
- ❌ **忽视电梯厅空鼓**——上方瓷砖空鼓要修，怕后期脱落；2026-08-21 电梯厅墙面大面积空鼓（墙根集中），收房前务必复验。
- ❌ **被"换砖"拖延带偏**——空鼓修复若开发商提"换砖"多是拖延，最终会让你选注浆（打孔注浆修复后看不出）；明确要求注浆即可。

## ⏰ 最迟决策时点

- **收房前**完成全部验房 + 问题整改清单确认。
- 验房发现的问题，**当场找物业打负责人电话、盯着修**；后续问题统一批量修。

## 🧭 验房要点（照着查）

### 空鼓检查（最重要）
- **卫生间 0 空鼓**（底线），其他位置问题不大、补了最好。
- 自检方法：拿小棍敲，听声音（空鼓声脆）。
- 空鼓解决流程：切割开 → 填充水泥 → 表面抹平。

### 重点区域
| 区域 | 要求 |
|---|---|
| 卫生间 | **0 空鼓** |
| 电梯厅 | 墙砖空鼓重灾区，上方瓷砖空鼓要修 |
| 拐角/踢脚线 | 空鼓最多，重点查 |

### 其他质量问题
- 天花板裂缝：可能是保温层导致，铲了墙灰可能没问题。
- 窗户异响：合页问题，让师傅调一下即可。
- 玻璃：检查划痕、气泡；玻璃质保问题见 [[14-小区与维权]]。
- **顶上保温层（2026-08-28）**：有业主咨询物业/工程部确认，**交付状态的顶上保温层表面是水泥灰**（非腻子）。

### 整改现状
- 整改速度慢；快修队在集中交房期间可边验边修。
- 空鼓整改周期可能较长（有半个多月未完成的案例）；建议整改完成再确认收房（2026-08-19）。
- 2026-08-21：电梯厅墙面大面积空鼓，业主只能周末对接物业，整改多时未完成；物业人力少、招不到人。

### 收房流程与费用（2026-08-19）
- **流程**：收房程序简单；自装签自己，由装修公司施工的把对接人叫上。
- **费用**（125 户型合计 5000 多元）：半年物业费（从交房起算）+ 装修押金 **2000 元** + 装修管理费 + 小件垃圾清运费。
- 物业费减免政策**尚未正式签署**，只能顺延；物业费起算时点可提出异议（有业主寄拒收通知书，物业以未收到为由不承认）；130 户型面积更小、物业费反而更高。
- **收房礼品对比**：戴森 HD16 吹风机×2+电饭煲（有转卖 1900 元）/ 华为平板 / 3K 购物卡 / 小米电饭煲 / 小米吹风机 / 微波炉 / 破壁机 / 仅饮用水与简餐（首开阶段）。开发商赠送：两个吹风机+电饭煲；电炖锅/空气炸锅二选一。
- **买房中介返点**：买房时中介有提成，可尝试要求返点（有业主成功）。

### 房产证线上申领（2026-08-22）
- **方法**：微信公众号「长沙不动产登记」→ 办事大厅 → 线上申办 → 纸质证书申领。
- **无需收房**：没交房/贷款没还完也能领（没收房不影响房子归属）。
- ⚠️ **电子证照判断**：只有一张电子证照 = 预告登记那张，正式登记的证书还没办好；办好后才有纸质证书（有业主能查电子证照但无纸质证书 = 正式登记未办好）。
- 实测效率高：昨天申请今早就到。
