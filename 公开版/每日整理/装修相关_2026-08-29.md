## 一、顶面抗裂砂浆层 / 保温层：铲还是不铲（🔴 重点）

### 🔴 专业讲解（施工方分享）

> 顶部不是保温层也不是隔音层，是**聚丙烯防开裂砂浆层 + 挂网防开裂底灰**。作用：楼板浇筑时有伸缩缝，防止后期刮腻子开裂。

- **为什么不建议铲**：这是一层防开裂处理，铲了反而容易后期开裂。
- **正确流程**：水电之后用**空鼓锤检查**，只有空鼓、脱层才需要铲；没有空鼓不用动。
- **表面浮灰必须去掉**：即使不铲，也要把抗裂砂浆表面浮灰扫掉，检查排除不能省略。
- **已铲除的补救**：等彻底干透后，刷界面剂 + 挂网 + 防开裂底灰，再做后续工序。
- **飘窗附近提醒**：顶部临近飘窗处有约 **20cm宽、3cm厚** 的混凝土条，铲不动，会形成 3cm 高低差，需要**做吊顶遮掩**。
- **补充**：顶面处理不是与楼板一体浇筑，多为挂网后做的保温砂浆层（含纤维材料），铲除耗时耗力耗钱；工程方与设计方均不建议铲。

### 🟡 群友讨论

- 有业主反馈"工程那边说一体浇筑别铲"，也有观点指出不同材质不可能一体浇筑，应以空鼓检测为准。
- 已铲除的业主表示"能不铲就不铲，已铲要重新处理；除非空鼓开裂，否则只需扫掉抗裂砂浆表面浮灰"。

## 二、中央空调：格力缺货、渠道与性价比（🔴 重点）

### 🔴 现状

| 品牌/渠道 | 现状 | 说明 |
| --------- | ---- | ---- |
| **格力 STAR5** | ⚠️ **已没货** | 原团购渠道已停止接单，部分门店"没了" |
| **colmo 新象 / 新象 Pro** | ✅ 推荐 | 价格与主流渠道差不多，**新象 Pro 性价比最高** |
| **美的（门店渠道）** | ✅ 有货 | 门店在**越兴电器城/金桥国际软装灯饰城 W208/W209**（美的智慧家），**有货、送前置** |

- 有业主因没提前定空调而后悔："设计稿没搞好想等等，结果上火箭了"。
- 多位业主提醒：**中央空调要尽快定，不然都没了**。

### 🟡 决策提醒

- **先定空调再设计**：吊顶高度宽度和中央空调都有关系。
- 中央空调外机尺寸大致差不多，除非买特殊**超薄内机**。

## 三、砸墙师傅选择与价格行情（🔴 重点）

### 🔴 优质师傅特征

- 推荐的师傅施工**以切割为主、电锤为辅**，切面整齐；**报价后无增项**（后续增加顶面局部拆除等活未加钱）。
- 对比：有业主反映自家墙被切得坑坑洼洼，砸墙质量参差，选师傅需看工艺。

### 🟡 价格行情

| 面积 | 价格 | 备注 |
| --------- | ---- | ---- |
| 109㎡ | **2100** | 有保温层 **+200** |
| 133㎡ | **2000** | |
| 另一家（109㎡级） | 2500 | 可谈折扣 |

- **避坑提醒**：铲阳台保温、两个卫生间防水、砸非承重墙**都是加价项**，报价前要问清。
- **铲卫生间防水务必提前谈好**：有业主 300 元两个卫生间防水只铲墙的（很贵）。
- 有业主反映出现过砸墙师傅砸到承重墙后扯皮的纠纷，动工前应确认拆改范围。

## 四、门禁面板：尺寸与更换（🟡）

- **实测尺寸**：**17.9 × 11.7 × 2.5 cm**（开发商标配）。
- **质感**：部分业主反馈面板较轻、塑料感强。
- **升级建议**：可换**智慧大屏**（需确认接口与电源）。
- **安装位置**：常见做法是**装在玄关柜里面**；⚠️ **面板位置要预留电源**（有业主反馈忘记留电源只留了插座）。

## 五、封窗与铝合金门窗（🟡）

- **商家动态**：部分封窗商家较佛系——"要把样板房做好后有实物了再宣传"，仍在正常接单。
- **价格**：市场已**卷到各家相差十几二十块**，差异不大，主要看顺眼与售后。
- **售后是核心考量**：有业主计划把**所有铝合金门窗交给一个商家**统一做，以便售后有保障。
- 建议**货比三家**，跟着靠谱的邻居一起订，还可能拿到更低价格。

## 六、全屋定制（🟡）

- 有业主认真比较后，计划找**某栋某户的全屋定制商家**（口碑"太实在"，有自己的定制厂与工厂资源，板材品牌授权齐全）。
- 老客户反馈："还好我选了他"，并说明自己只是客户、无返点。
- 与该商家合作前建议继续对比板材与报价。

## 七、瓷砖（🟡）

- 有业主暂定**东岸一家瓷砖店**（"带懂行的长辈去验过，说没问题"）。
- 群里多个同姓商家易混淆，认准具体门店；参考品牌：冠珠、马可波罗。

## 八、奢石选购：普拉达绿（🟡）

- **普拉达绿**市面常见、**不贵**：贵的约两千多/平，性价比款也能找到。
- **小面积（1-2平）做岛台/吧台**比较划算；颜色不同也可以和邻居拼单。
- 可找有经验的商家推荐靠谱渠道。

## 九、实木家具：朴愫木作（🟢）

- 有业主探店后反馈：**朴愫木作（万家丽点）实木家具不错**，值得看看。

## 十、新风系统参观（🟢）

- 有业主想参观已安装新风系统的家庭学习，计划相互交流参观。

## 十一、小区与施工动态（🟡）

- **南北地块差异**：北地块公共区石材**面积更大、更平整**；南地块部分闸机入口路面有波浪形，**进出易磕底盘**，可作反馈点。
- **电动车进小区**存在安全隐患，早前已有改进诉求。
- 部分装修样板间**参观需提前预约**（业主不在现场时不便接待）。

## ⚠️ 避坑提醒

1. ❌ **顶部抗裂砂浆只铲灰不处理** — 铲了必须补救（界面剂+挂网+防开裂底灰），否则后期开裂；表面浮灰要清掉。
2. ❌ **铲卫生间防水/阳台保温/砸非承重墙不问价** — 都是加价项（防水 300 只铲墙）；动工前务必谈好。
3. ❌ **盲目等货** — 格力 STAR5 已没货；先定空调再设计吊顶（高度宽度都有关联）。
4. ❌ **外立面玻璃幕墙封填缝用白色泡沫板外露** — 外观不佳，可要求换深色隔板或贴膜，最好同栋统一。
