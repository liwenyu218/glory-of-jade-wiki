## 一、物业/工程部"梁上不能打孔"集中反映（🔴 当日最大话题）

> 起因：有业主反映物业上门说"梁上不能打孔"，随即引发 4 家业主集中吐槽。

### 🔴 集中反映：口径统一"不能确认、后果自负"

| 业主反映 | 遭遇 |
| ---- | --------- |
| 业主 A | "今天物业过来跟我说梁上不能打孔"；师傅把打孔位置画好了，来一句"不能打、要业主到场确认" |
| 业主 B | 物业也说梁上不能打孔，指着对面楼上好几家说"你看别人每家都好几个孔" → 对方回"**你打吧，出了问题自己负责就行**" |
| 业主 C | 打电话请物业工程部来确认打孔，对方说"可以给你看看，但是**不能给你确认能不能打，出了问题你们自己负责**" |
| 业主 D | "也是这么和我说的" |
| 其他业主 | "我们装的早的就可以打孔"；**某品牌空调打孔是试着打，如果里面有钢筋就停、换成水泵** |

- 🔴 **事故提醒**：有业主提到"听说昨天有一家装空调**打到消防管道**了"。
- 🟡 有业主认为："打孔没什么关系，而且就几个孔，物业硬要这样卡""问他们能不能开都是含糊其辞，就是你想开也能开、出问题了不担责的那种"。
- 🟡 **服务体验反馈**：有业主反映工程部人员上门时态度一般、**在业主家到处拍照**（称"开槽碰到箍筋有风险"）；另有业主反映工程部**巡查记录存在一次性补填多日**的情况——建议**装修期间留证、必要时投诉**。

### 🔴 沟通话术参考

> "你有权否定我们的定位方案，但请你提供一套可行方案？或者你告诉我该怎么装挂机的方案。"

- 该业主反馈：去了**多批工程人员**都没一个说可以打，上压力后对方才说"试着打"；"我说跟师傅对接，我不打孔，然后丢下一句反正按要求来"。
- 结论：**打孔问题本身不大**，关键是责任归属需要提前说清。

### 🔴 门上方梁有厚钢板 → 新风做不了

- 有业主反映：**门上方梁内有两块厚钢板（主承重）不能打孔** → "**今天新风都没做，就是因为这个房间做不了新风**"。
- 替代方案：从**公卫墙打孔做挂机**（有业主建议）；⚠️ 但**挂机外机+中央空调外机叠放会偏高**，生活阳台会被挡完（该户型生活阳台本就小）。

→ 详见知识库《中央空调》《小区与维权》

### 🔴 生活阳台吊顶

### 🟡 生活阳台太小：晾衣与空调外机抢空间

### 🔴 143 户型大改造范本：三卫改两卫 + 公卫改衣帽间

- **方案**：
  - **砸掉公卫改衣帽间**（原有三个卫生间 → 砸一个公卫 → 剩主卧一个 + 娱乐室一个）；
  - **娱乐室**（朋友来了估计在娱乐室呆得比客厅久）；主卧卫生间**新建一面墙**（回应"马桶只能靠墙、管道在墙这边"的疑问）；
  - **绿植墙**（"洗澡会有热带雨林的感觉"）；
  - **去客厅化**：没有电视机、客厅不做鞋柜，**入户厅放成品鞋柜+椅子**。
- **造价与施工**：
  - **半包 850 元/㎡**；有业主估"全落地要 60"；本人"力争控制在 **50 以内**"、"天天和设计师聊到底怎么落地最省钱"。
  - 施工方：**禧施工**；设计费 **80 元/㎡**。
- **群内反应**："这个思路启发我了""这个设计太爽了""这套好看"；也有人质疑"**不要公卫，客人来家里上厕所去哪**""主卧卫生间这样改确定可以？"。
- **顺路组团（该业主）**：5 户成团工程款 **95 折**+送 3 樘卧室门；10 户 **9 折**+送厨卫美缝；15 户 **88 折**+送全房开关。
- 🟢 **165 户型**：有业主感叹"小区还有 165 户型一个人住的，真爽"；"我一家四口住，143 没啥能改动的空间"。

## ⚠️ 避坑提醒

1. ❌ **物业工程部说"梁上不能打孔、后果自负"** — 多家集中反映，口径统一但**不提供可行方案**；可反制："你有权否定我们的定位方案，但请你提供一套可行方案"；某品牌做法=试着打、遇钢筋停换水泵。
2. ❌ **门上方梁有厚钢板（主承重）误打** — 会导致新风/挂机方案被迫改；打孔前务必确认门上方/窗上方梁内是否有钢板。
3. ❌ **砸墙只看"基础价"** — 1500 只包基础拆除，**磨漆/破皮/移门/拆小垛子/扩门洞/铲顶灰都另算**；动工前把增项谈清写进合同。
4. ❌ **盲信户型图判断承重** — 有业主家"墙和图纸不一样"、实为一体浇筑；拆前探墙 + 找物业确认。
5. ❌ **贪便宜被"AB 货"坑** — 有经验提醒"有些公司给你选 AB 货"；柔光砖要买好一点的砖（划痕/打理问题多是砖质量差）。
6. ❌ **轻信冒充"物业工程部/邻居"上门或电话** — 警惕陌生上门/来电；邻居一般只用微信；管好门锁密码。
7. ❌ **门/窗上方梁打孔做新风或空调** — 先确认梁内是否有钢板（主承重），否则方案会被迫改（可考虑公卫墙打孔）。
8. ❌ **买电器轻信"内部价"** — "内部价未必是底价"，建议多方比价、等大促。
