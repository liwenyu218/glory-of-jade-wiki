## 一、全屋组网（Mesh vs AP，核心讨论）

### 🔴 结论：Mesh 路由够用，不必上 AP

- **AP（吸顶/面板）缺点**：面板 AP 可能熏黑墙面（散热问题）、价格贵、损坏后检修需爬顶、需加 POE 供电（弱电箱空间不足）、覆盖不到卫生间。
- **Mesh 组网**：埋好网线放 2-3 个路由组网即可满足多数户型；多个路由 Mesh 后相当于一个 WiFi、自动切换；有线 Mesh 稳定、无线不稳定。
- **AP 适用场景**：大平层、别墅或跨层户型。
- 已有业主最终决策：不装 AP，改用有线 Mesh。

### 🟡 网线标准与布局

| 项目 | 结论 |
|---|---|
| 网线规格 | **超六类足够**（6G 时代优势明显、支持万兆）；也可六类线+光纤一起埋（六类管当下、光纤支援未来） |
| 每房间 | 每个房间留一根网线；卧室路由器接网线、必须有线连接 |
| 电竞房 | 预留 3 个网口（多数装修公司不加钱）；插座需另外加钱（全屋 80+ 插座） |
| 弱电箱 | Mesh 方案弱电箱和主路由之间留 2 根网线；主路由直接放弱电箱更省事 |
| FTTR | 部分运营商 1000M 宽带强制搭配 FTTR 设备，需注意资费方案 |

### 🟢 其他

- 多个 Mesh 路由组网后信号覆盖"基本无敌"；客厅一个+主卧一个基本够用。
- 网线规格升级无需过度投入：六类/超六类已满足当前与近期需求，路由器升级即可提升网络。

## 二、收房全流程（费用 / 礼品 / 物业费）

### 🔴 收房费用（实测分享）

| 项目 | 金额 |
|---|---|
| 半年物业费 | 按面积收（从交房起算） |
| 装修押金 | 2000 元 |
| 装修管理费 | 按面积收 |
| 小件垃圾清运费 | 按项收 |
| **合计（125 户型）** | **5000 多元** |

- 自装签自己；由装修公司施工的把对接人叫上。
- 物业费减免政策**尚未正式签署**，只能顺延。
- **物业费起算时点可提出异议**（有业主寄拒收通知书，物业以未收到为由不承认）；130 户型面积比 125 小、物业费反而更高。

### 🟡 收房礼品（各业主对比）

| 礼品 | 实例 |
|---|---|
| 戴森 HD16 吹风机 ×2 + 电饭煲 | 部分业主（有转卖 1900 元） |
| 华为平板 / 笔记本 / 3K 购物卡 | 其他业主 |
| 小米电饭煲 / 小米吹风机 / 微波炉 / 破壁机 | 其他业主 |
| 仅饮用水与简餐（首开阶段） | 早期收房业主 |

- 开发商赠送礼品：两个吹风机+电饭煲；电炖锅/空气炸锅二选一。
- **买房中介返点**：买房时中介有提成，可尝试要求返点（有业主成功）。

### 🟢 收房与整改

- 空鼓整改周期可能较长（半个多月未完成的案例）；建议整改完成再确认收房。

## 三、中央空调

### 🟡 外机平台打孔

- 物业来多批人员**均不能确认**能否开孔；实测**外机平台有梁可以开孔**（多数业主已开）。
- 外机叠放存在争议（部分认为可以叠放）。

### 🟡 品牌口碑与报价

| 品牌/型号 | 价格/评价 |
|---|---|
| 日立舒享（一拖四） | 京东约 2.5w |
| 三菱 | 报价无型号无参数难以定价；**三菱重工与三菱电机口碑差异大** |
| 格力 | 团购被同行举报后仍有其他渠道 |
| 日立/约克 | 考虑中，价格偏高 |
| 大金 | 无自有装修团队 |

- 部分品牌团购因价格过低被同行举报（业内竞争现象）。

### 🟡 智能空调联动

- 米家可同步接入部分品牌照明/空调生态（领航者四代等）。
- 智能空调接入米家需 VRF 连接器（官方约 1288 元，二手平台约几百元）；部分品牌（如格力）有自有 App。

## 四、全屋定制

### 🔴 金属衣柜团购

- **舍尔弗金属衣柜**：L 型收纳空间更大、全部挂衣区；**凑 20 人团购打 88 折**。
- ⚠️ **不要在网上询价**（会锁后台、失去团购折扣）。
- 金属衣柜为成品、无需与墙面连接固定；可在柜门装镜子。

### 🟡 定制供应商

- 有业主做全屋定制：长沙多家工厂合作、各品牌板材都有授权（含巴西博耐克），自己有湘阴定制厂股份，可对接。
- **800 库方案**：生活阳台可打家政柜+800 库；需权衡洗衣池空间（有设计师提示会牺牲洗衣池空间）。

### 🟡 主卧衣柜

- 方案一：主卧不放衣柜（保留睡眠属性），床尾放长脚凳挂衣、淋浴间设次净衣区。
- 方案二：与样板间一致、卫生间一侧做柜子。

## 五、厨卫

### 🟡 石英石台面挡水边

- 本地**没有一体成型的挡水边**，只能用石英石打磨（效果一般）。
- 挡水边"鸡肋"、容易藏污纳垢；石英石没有纯色（人造石可做纯色）。
- 700 为台面宽度；厚度 1.5cm / 2cm 可讨论。

### 🟡 洗碗机

- 某品牌价格实惠、某进口品牌价格较高；晶蕾系列关注度高；部分品牌（方太）有渠道可议价。

### 🟢 燃气灶 / 燃气热水器

- 家用燃气灶火力 **5kw 够用**，极限可到 5.2kw。
- 燃气热水器选型（当日未定论）。

## 六、门窗与封阳台

### 🟡 纱窗

- **纱窗不必着急安装**，可等保洁完成后再装。
- 隐形金刚砂纱窗在高层较好用；各种纱窗外观一般。
- 纱窗需带护栏（安全考虑）。

### 🟢 封窗玻璃

- 生活阳台一半已有玻璃、只能封另一面时，**两面玻璃挨在一起可能爆裂**——封窗前与商家确认旧玻璃处理方案。

### 🟢 电梯厅飘雨

- 有业主实测高层电梯厅飘雨较严重（不同楼层/朝向情况不同，需实地确认）。

## 七、强电箱与燃气管

### 🟡 强电箱 / 空气开关

| 方案 | 价格 |
|---|---|
| 某品牌总代 EA9 | 约 1500 元 |
| 全包方案（R9 带漏保） | 1200 元 |
| 电工师傅推荐款 | 800 多元（质量存疑） |

- 验房师傅反映**电箱偏小**，装修公司要求重新购买、不包含在报价内。
- 可留意是否有组织团购。

### 🟡 燃气管

- **主管道不能改**（只能改表的高度位置）；需**申请燃气公司**操作、自己不能动、另付费用。
- 125 户型煤气管不能改门：改**折叠门**（封窗情况足够）或**平开门**（密封性好、便于保洁）。

## 八、小区与维权

### 🔴 入户门渗水（多户反馈）

- 多户业主反映入户门渗水；物业称是水管问题，施工方判断大部分不是厨房来水（厨房地面较低）。
- **电梯厅地漏存在断层**——可往电梯厅地漏倒水验证。

### 🟡 维权落实进度

- 车牌录入"下周一之前"仍未收到通知；物业费补偿也未通知。
- 有顶楼业主准备起诉开发商。

### 🟢 公区问题

- 车库花岗岩铺设量不足（比设计图少）、石块未铺完、行车有异响；下坡未做防滑石材。
- 垃圾站是否装门（担心异味影响相邻楼栋）。
- 公区顶灯色温偏黄。

## ⚠️ 避坑提醒

1. ❌ **上 AP（吸顶/面板）** — 贵、难检修、面板会熏黑墙面；Mesh 路由足够
2. ❌ **金属衣柜网上询价** — 会锁后台、失去团购折扣
3. ❌ **铲反地梁** — 确认是反地梁后必须停手
4. ❌ **自行改动燃气管** — 主管道不能动、只能申请燃气公司
5. ❌ **两面玻璃挨一起封窗** — 可能爆裂
6. ❌ **忽略电梯厅地漏断层** — 入户门渗水疑点之一
