## 一、验房收房（空鼓 & 注浆）

### 🔴 重要提醒

- **电梯厅墙面大面积空鼓**（SS 反映）：空鼓多集中在墙根位置，收房前要复验
- **注浆修复**：注浆即打孔注入浆料，修复后基本看不出来；开发商若提"换砖"，本质是拖延让你最终选注浆
- 物业整改慢：业主只能周末去对接，整改多时未完成；物业人力少、招不到人

### 🟡 保温层

- 顶保温**物业不让铲**；有施工师傅称质量好不要铲；验房方称工艺不好会脱落；也有业主认为看运气

## 二、中央空调 & 挂机之争

### 🔴 挂机 vs 中央空调（实测推演）

- **挂机方案**（格力 K+ 8.5KW + 主卧 2 匹挂 + 1.25 匹×3）：比中央空调便宜约 **6000 元**
- ⚠️ **坑1**：冷凝水排水管入墙，管壁会露水、影响墙灰
- ⚠️ **坑2**：铜管过长需加压加氟，压力大易渗透
- **结论：对比后还是选中央空调**
- 除 117 户型外，其他户型阳台放挂机基本没位置
- 外机位（中间户）：阳台空间大，可一排放 2 个、做架子上面再放 2 个

### 🟡 外机位填不填

| 做法 | 优点 | 缺点 |
| ---- | ---- | ---- |
| 不填 | 散热好、电耗低、不易频繁启停 | 视野差 |
| 填 | 视野好 | 散热差、电耗增加、频繁启停 |

### 🟡 安装验收标准（口碑案例）

- 有安装团队采用 **40kg 打压 48 小时 + 充氮焊接**，装好后打压数值多日不变（漏压即返工）
- 选安装团队时问清：是否充氮焊接、打压多少公斤/多久，验收时亲自核对压力表

### 🟡 儿童房空调

- 有业主反映儿童房布局空调没办法不吹头，讨论出风口遮挡 / 感应空调方案

## 三、全屋智能

### 🟡 两大方案

- **小米 / 欧瑞博** 是主流两大选择
- **欧瑞博**：做集成——把空调、地暖、新风集中到一个模块，中央控制系统大屏控制；别墅项目多；压缩机采用松下
- **自装米家方案**：自己买设备自己做，窗帘包安装，自装加窗帘轨道约 **3K 左右**
- **水电预留**：轻智能要留零线，窗帘要留插座

## 四、新风 & 燃气

### 🔴 新风关键信息

- 本小区**新风进风口在电梯厅**
- **新风不能和锅炉（燃气热水器）放一起**：锅炉排废气、新风吸新鲜空气互相干扰；有新风+地暖+锅炉的，要空调方出集成方案
- **新风管道只能找物业打孔**

### 🟡 新奥燃气套餐（实测价目）

| 项目 | 内容 |
| ---- | ---- |
| 套餐价 | **1980 元**（7 米管道：从燃气仪表位置到最下游节点） |
| 包含 | 管路铺设、开槽施工、各种套件、燃气仪表在主管上挪位置（仅限上下调整） |
| 超出 | **每超 1 米增收 100 元** |
| 燃气主管美化 | **仅允许可拆卸扣板/挡板形式包覆** |
| 主管凹进墙体 | 新增墙体面留 **40-50 公分** 焊接维修/检验空间 |

### 🟡 开发商预埋线管积水（实测提醒）

- 部分户型**开发商预埋线管内有水泥水渗入积水**（该位置略低）
- ⚠️ 施工穿线/拉线前先排水，**避免拉爆线管**

## 五、窗户打胶 & 窗框下沉

### 🔴 玻璃补胶必须返工

- 部分施工队打胶时**没打玻璃下方两个位置**：**窗框下陷区域、主卧转角区域**
- 砸完墙后家家户户都要做玻璃补胶；现场师傅称打了多户都没做过这两个位置
- **应对**：主动盯这两处，师傅说"打不到"可用工具辅助（如用管子引流），不能放过

### 🟡 窗框下沉 / 立缝处理

- 有专业团队提供**立缝与下沉处理方案**（含实际落地案例）：精工保护（地面软包地膜 + 石膏板）
- 同类楼盘（招商蛇口臻境）同样存在窗框下沉，由开发商交房时处理
- 大平层项目有实际落地方案，地面方案陆续出来

### 🟡 飘窗坑填充价格

| 项目 | 价格 | 做法 |
| ---- | ---- | ---- |
| 飘窗坑填充 | 约 **3000 多** | 轻质砖填充；铝板可弯、与玻璃间垫垫片；**瓷砖通铺后打玻璃/结构胶** |
| 某项目同款坑 | 1000 多 | — |
| 桃粒回填方案 | — | 有业主选**桃粒回填**（尚未施工） |
| 加玻璃下沉一起做 | 约 +1w 预算 | 估算 |

## 六、装修公司 & 施工队

### 🟡 大公司客户经理流失风险

- 有业主定某知名装修公司，**付了 1.2 万设计费后客户经理调去别处做总监、没人管**
- 群内建议：**把施工打卡/节点记录作为付款条件**；或考虑退，换口碑设计师（有推荐：设计施工一起盯，此前公司 88 元/平）
- 启示：**付款前锁定责任人 / 写入打卡机记录核对条款**

### 🟡 拆除队避雷补充

- 此前被实锤避雷的拆除队（乱尿/拖延）**拆了 1 周没弄好**
- 推荐口碑师傅；拆墙/装修期间尽量**周末全天在场盯**

### 🟡 施工时间

- 有传"周六日禁止施工加强管理"，实际**没有禁止**（集中装修期周六日可施工）

## 九、小区配套

### 🟡 物业服务与装修秩序

- **工人乱尿问题**：装修期间部分楼栋通道被工人当临时卫生间，物业 5 点下班无人处理，业主投诉至 400

## ⚠️ 避坑提醒

1. ❌ **玻璃打胶漏打下方两处**（窗框下陷区、主卧转角区） — 盯返工
2. ❌ **付设计费不锁责任人** — 客户经理调走没人管的案例，付款前明确对接人
3. ❌ **挂机冷凝水管入墙 / 铜管过长** — 省 6000 但返潮、加压隐患多
4. ❌ **新风与锅炉同放** — 废气与新风互相干扰
5. ❌ **燃气主管封死包覆** — 仅允许可拆卸扣板
6. ❌ **电梯厅空鼓被拖成注浆** — 收房前复验要盯
7. ❌ **外机位填实** — 散热差、电耗增加、频繁启停
