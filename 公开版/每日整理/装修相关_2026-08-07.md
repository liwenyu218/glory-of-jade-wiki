## 一、天花板保温层（当日核心话题）

### 🔴 争议焦点：铲还是不铲？

| 立场 | 理由 |
|------|------|
| 铲除 | 怕乳胶漆开裂脱落，铲掉可加高几寸层高 |
| 不铲（做吊顶） | 吊顶可完全覆盖，不影响隔音保温 |
| 不铲（石膏板封） | 比吊顶便宜，比全铲省事 |
| 不铲（搏一搏） | 开裂再修补，省成本 |

### 🔴 厚度争议

- 有业主：楼板加保温板厚度15cm，顶部保温层约**8cm**，铲掉只剩7cm
- 另有业主：问过管家，工程部回复**约3公分**
- 8cm vs 3cm 说法不一，需自行实测确认

### 🟡 四个方案总结

1. 铲掉天花板保温层 → 影响隔音隔热
2. 全做吊顶 → 费用高但彻底
3. 直接用石膏板封住 → 省钱省事
4. 先不处理，后期开裂再修补 → 搏一搏

### 🟢 业主实践

- 有业主主卧餐客厅有吊顶所以不用铲，两个次卧需要铲
- 有装修公司建议铲，说"后期怕全部掉下来"
- 不同装修公司建议不同，需自行判断

## 二、全屋定制团购

### 🔴 工厂店报价

| 项目 | 详情 |
|------|------|
| 总价 | **约46,000元**（含所有柜体+柜门+3个房门） |
| 板材 | 枫树山板材 + 夏特木饰面（780元/平） |
| 面积 | 约四五十平 |
| 包含 | 橱柜吊柜、玄关柜、岛台、餐边柜、电梯厅柜、两个浴室柜、生活阳台家政柜和吊柜、书房书柜、所有衣柜柜门、三个房间门 |
| 不含 | 衣柜内部金属架子 |

### 🟡 价格来源

- 有业主做工装设计，在工厂店拿板材很划算，成本价给邻居
- 设计师价格一般700多一平，团购价做到580元/平
- 业主提醒："买卖自由，自行负责"，"跟不跟是大家自己选择"

### 🟡 金属衣柜 vs 全屋定制

| 方案 | 优点 | 缺点 |
|------|------|------|
| 金属架子+定制门 | 性价比高，质感好（舍尔弗） | 需分开找，砍价难 |
| 全屋定制一体做 | 省事，颜色统一 | 贵很多 |
| 纯全屋定制 | 省心 | 价格高 |

- 有业主在研究舍尔弗金属衣柜，砍价到5个点折扣，但还砍不动
- 有业主评价舍尔弗是行业内做得比较好的，有质感，但价格有点刚

### 🟢 不锈钢台面

- 有业主组织不锈钢台面团购，**980元/平**
- 看了材质、性价比和售后，有品质保障

## 三、玻璃质量与维权

### 🔴 玻璃更换风波

- 有业主反馈：开发商中途没用咸宁南玻的玻璃了，换其他厂了，质量不敢保证
- 开发商声称该小区玻璃等级比另一个小区高，但另一个小区是三层夹胶玻璃、双中空
- 各栋楼玻璃品牌可能不同

### 🔴 业主维权行动

- 有业主因落地玻璃问题决定不收房
- 问题：玻璃碎了要拆地板、拆护栏、拆墙，维修成本极高
- 第一次维权提过玻璃质保，没给答复
- 玻璃质保等下次开会再回应，开发商要商讨同步解决窗框和玻璃保护问题

### 🟡 玻璃质保要求

- 目前开发商给的质保期太短（约2年）
- 业主希望延长到10年及以上

## 四、纱窗与封窗

### 🟡 纱窗安全讨论

| 方案 | 特点 |
|------|------|
| 护栏+纱窗 | 安全，但护栏丑 |
| 隐形护栏 | 贵，好看 |
| 半高玻璃 | 安全但不太好看 |
| 仅纱窗 | 打开纱窗时开口太低，有坠落风险 |

- **共识：有小孩必须有护栏，没小孩也建议装**
- 有业主："没小孩我都怕自己不小心栽下去"

### 🟡 封窗现场比价

- 有业主家组织多个封窗厂家现场报价
- 有业主建议："找三个厂家带着各自的样品一起来，直播开个竞品会"
- 十个门洞报价四千多，加了纱窗后价格有所增加

### 🟢 纱窗价格参考

- 有邻居卖纱窗 **295元/平**，超过1平多一点点需另谈
- 有业主从工厂报价，**比纱窗团购低了5000总共**
- 护栏一定要带，加钱也要

## ⚠️ 避坑清单

1. ❌ 天花板保温层厚度说法不一 — 8cm vs 3cm，需自行实测，不要完全相信某一人说法
2. ❌ 玻璃质量隐患 — 开发商中途换玻璃厂，落地玻璃碎了维修成本极高，需关注质保期
3. ❌ 纱窗只装一种 — 护栏+纱窗都要装，打开纱窗时开口太低有坠落风险
4. ❌ 全屋定制盲目跟团 — 各家户型不同需求不同，自行对比后再决定
5. ❌ 空调外机位铝板自行拆除 — 物业大概率不让动，不要擅自动
