## 一、拆除队避雷（当日最大事件）

### 🔴 重要提醒

**某拆除队「今旺」多宗劣迹实锤（2026-08-20 晚）：**

- **团队混乱**：一个团队几个分支互相推诿，出事就说不是一起的

## 二、中央空调（当日大热话题）

### 🔴 核心动态

- 有业主家（1-2203）**格力中央空调安装完工**，上午格力销售到场，业主可参观
- 有业主**最终定了美的领航者**（天氟地水），分享 PDF 配置文档；洋湖京东mall 只能做领航者 3.0 / 新象 2.0

### 🟡 品牌对比讨论

| 品牌/型号 | 价格参考 | 评价 |
| --------- | -------- | ---- |
| **格力 Star5（S5）** | 一拖六约 5.4万（含地暖） | 有业主选择；当天完工 |
| **海尔铭家 M6** | 一拖四约 23000，厨房空调加 3600 | 性价比讨论 |
| **海信** | 一拖六约 2.8万 | 便宜 |
| **美的领航者 4** | 一拖四 160 外机约 **2.63万**；加厨房空调约 **28750** | 天氟地水；有业主最终选择；洋湖京东mall 只能做 3.0 |
| **COLMO 新象 pro** | 加厨房内机 +2500 | 洋湖京东mall 只能做 2.0 版本 |
| **三菱重工海尔** | — | 部分业主支持 |

**洋湖京东mall 限制**：只能做领航者 3.0、新象 2.0（非最新版）。

**领航者4 价格动态**：有业主反映"陈总那边好像做不了之前的价格"；有业主支招"加两千，然后让他在别的电器里给你减点"；也有业主表示仍是原价（付了定金的是原价）。

**厨房空调加价参考**：海尔 +3600；COLMO 加厨房内机 +2500，且可能要增大外机。有业主质疑厨房空调必要性（"夏天做饭不会一直泡里面"），但"固定某个人一天三顿做饭就有必要"。

### 🟡 空调选购经验

- **内机带泵**：有业主不选（怕噪音）；也有认为"无所谓，带有带的好处"
- **低频技术**：4Hz 低频省电，"只要有低频运行这个技术就行了"；但"低频都是有触发条件的"，只开最小内机（22）时 4Hz 最有效
- **智能联动注意**：⚠️ 部分品牌线控器接全屋智能有延迟（有业主反馈"10多秒"）；智能联动口碑较好的是荣耀家、美的
- **格力渠道**：东岸李总那定格力"包落地价，管道加长不收钱，不做团购，可以推名片"
- **两联供 vs 锅炉**：**两联供要两万多**、还得配热水器供应生活热水（一个热水器一两千）；后期能耗小（用电）；前期投入贵很多；锅炉烧燃气。"冷凝炉地暖+热水就行"是多数共识方向
- **地暖品牌**：有业主做 **菲斯曼 B1** 系列（格力 Star5 一拖六 5.4万含地暖）
- **品牌格局**：群友观察"空调大部分都是日系，国产就是格力、美的"

### 🟢 群友共识

- 中央空调在水电之后安装，与封窗一起进行

## 四、水电验收（有业主家次日验收）

### 🔴 验收要点（群友汇总）

**有业主家（1-2002）水电走完，8-21 验收，群里"有偿找茬"（红包1元/个问题）：**

| 检查项 | 结论 |
| ---- | ---- |
| 回路数 | **至少 7-9 个**：冰箱、弱电箱、内机、外机、厨房、卫生间×2、照明、插座×2；有业主家 12 个回路（"正常10平方一个"） |
| 强弱电交叉 | **强电要包锡箔纸**（有业主家强电没包，算一个问题） |
| 水管打压 | **水管接完要打压测试**，没问题之后才能验收 |
| 弱电插座 | 不能断电，断电了没网 |
| 横槽 | 无横槽较好 |
| 墙固地固 | 看情况（见下节） |
| 监理 | 有业主建议请监理；也有认为邻居们都很懂、不用请 |

### 🟡 施工工序讨论

- **一业主家顺序**：水电 → 木工（吊顶）→ 中央空调+封窗 → 瓷砖 → 刮腻子 → 全屋定制 → 刷漆 → 装柜门
- **先进木工原因**：怕木工搬梯子磕坏瓷砖、封窗玻璃刮花瓷砖、书房吊平顶要塞下出下回（与空调联动）
- 也有观点：先进瓷砖收口更漂亮、柜子下面可做追缝；但进柜子后再铺瓷砖只能用收口条 → **做地面防护即可**
- 卫生间吊顶：有业主做硅钙板（木工做，须先贴砖）；有打算铝扣板；也有推荐**防水石膏板**（好看）

## 八、装修公司避雷 & 设计讨论

### 🟡 装修公司避雷经验

- 有公司**不刷墙固地固**
- 设计模板化：效果图用酷家乐（非 3Dmax），被吐槽千篇一律
- 设计师水平参差：出现效果图不佳、推倒重来情况；有"护墙板太多"问题
- 🔴 **管理费高达 12%**（也有签 10%）；对比：部分施工队无管理费、部分公司 5%
- **吊顶 150/平 + 10% 管理费 = 165/平**；有业主装修公司算 3 万多，**另找监工搞只要 2.3 万**（部分项目可自行另找人做省管理费）
- **报价参考**：有业主"没啥柜子报价 20 个"、"不包柜子谈到了 15 万"；117 平签 18 万、有业主合同签 21 万；拆砌、美缝、灯具等写需业主自理
- 讨论中多位业主考虑**退装修公司**（先付设计费被套牢的风险）

### 🟡 全屋定制

- 有业主问"全屋定制自己找应该没有管理费吧"；有经验分享"**全屋定制自己去找，要便宜很多**"

### 🟡 净水

- 有业主**定了安吉尔全屋净水系统**
- 有净水商家在群内服务："邻居想装净水系统，我可以为邻居们服务，欢迎私信咨询"；有业主问"净水器有团购群吗"

### 🟡 设计风格讨论

- 极简最难把握
- 全白简约怕"五彩斑斓的白"
- 风格方向：法式原木中古 / 意式极简 / 韩系包豪斯（海盐系包豪斯）
- 有定制商家免费出效果图；全屋定制可先拿设计图
- 设计费按外框算还是内框：答外框

## ⚠️ 避坑提醒

1. ❌ **拆除队避雷** — 乱尿、砸承重墙、坐地起价、报价不报，全群实锤避雷
2. ❌ 拆除/砸墙**工人可能在毛坯房就地小便** — 尿骚味渗混凝土难清除，有时间要盯着
3. ❌ 只看低价拆除队 — "表面便宜、增项巨坑"，选口碑推荐的师傅
4. ❌ 弱电插座别和照明同回路 — 断电会没网
5. ❌ 水管接完**必须打压测试**再验收
6. ❌ 强弱电交叉强电**必须包锡箔纸**
7. ❌ 回路数过少（6个偏少） — 建议 7-9 个以上
8. ❌ 黄墙绿地可能是"形象工程" — 甲醛易超标，按需做（木地板才必要）
